Node pack reference

ComfyUI-AhmedAhmedEG

MiniMax H3 generation, shot continuity, references, refinement and export. Start with one working shot, then look up the node you need.

Getting started →Master Node reference
The basic workflow uses four nodes from this pack: Master Node, Director Settings, Reference Pack and Smart Preview. Model loaders and ordinary video saving use stock ComfyUI nodes.

Documentation index

Every node has its own page with behavior, wiring, a usage example, inputs, settings, outputs and limitations.

Output

MiniMax H3 Smart Preview

Plays completed cached shots in a separate node, with Latest clip and Full video scopes.

MiniMax H3 Video Combine & Audio Muxer

Encodes an IMAGE frame batch and optional audio with advanced codec controls.

MiniMax H3 Project / Shot Video Export

Exports cached project shots one at a time and assembles a native VIDEO file.

MiniMax H3 Playback / Watermark / Loop

Changes decoded playback timing, adds a watermark and optionally creates a loop.

Start here

MiniMax H3 Master Node

Authors and generates a timeline of MiniMax H3 shots with video and audio.

MiniMax H3 Director Settings

Builds the canvas, sampling and execution configuration consumed by the Master.

Enhancements

MiniMax H3 Director SelfLift

Configures a low-resolution sampling stage followed by a full-resolution finish.

MiniMax H3 Director Refine

Configures latent refinement or enlargement after the first sampling pass.

MiniMax H3 Director FaceRefine

Configures detection, tracking and refinement of one face in decoded video.

MiniMax H3 Director Semantic Bridge

Builds a configuration for adapting the text-conditioning tokens with a student network.

MiniMax H3 Cache

Patches an H3 model to reuse approximate block-stack residuals during sampling.

MiniMax H3 Pixel / RTX Upscale and Refine

Resizes decoded frames with bicubic, learned image upscaling or optional NVIDIA RTX effects.

Advanced graph tools

MiniMax H3 Director Group (Image to Video)

Packs one text/keyframe shot for the Master from graph inputs.

MiniMax H3 Director Group (Reference to Video)

Packs one REF2VA shot with graph-supplied images, video frames and audio.

MiniMax H3 Director Groups Combine

Flattens connected shot groups into a single ordered group list.

MiniMax H3 Tail From Latent

Decodes a sampled H3 joint audiovisual latent and returns its ending frames and audio.

MiniMax H3 Shot Model Pack

Registers named model overrides for individual shots.

References and prompts

MiniMax H3 Reference Pack (Pool)

Pools graph-supplied references for local selection on individual Master shots.

MiniMax H3 Prompt Forge Draft

Asks a local or server-accessible language model for a structured prompt draft.

MiniMax H3 Review / Apply Prompt Draft

Applies an accepted prompt draft to a timeline snapshot.

MiniMax H3 Local Prompt / Vision Model

Loads an installed local text or vision model for Prompt Forge.

Checkpoints

MiniMax H3 Load Take Checkpoint

Loads a complete saved take from a project’s server-side cache.

MiniMax H3 Advance Staged Take

Chooses explicitly between a current and a staged continuation checkpoint.
