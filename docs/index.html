Four useful distinctions

Pool ≠ assignment

Reference Pack prepares available assets. Each clip chooses its own subset.

Input ≠ output size

Reference Pack resizes inputs. Director Settings chooses the generation canvas.

Selected ≠ approved

The yellow outline chooses an editor target. Approval asks Master to reuse a result.

Refine ≠ resume

Refinement starts another stage; it does not append missing steps of a completed schedule.
