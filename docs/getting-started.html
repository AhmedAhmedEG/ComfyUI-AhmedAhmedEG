Before you touch a setting

A workflow is a set of connected nodes. Left sockets accept data; right sockets return it. MODEL carries weights, IMAGE carries pictures, and AUDIO carries a waveform. Matching types matter.

The starter already connects the core pieces. Select installed files, author a clip and run through its connected Smart Preview. You do not run every box separately.

In the node menu, Master and Director Settings are under ComfyUI-AhmedAhmedEG → Start here; Reference Pack is under References and prompts; Smart Preview is under Output. The guide navigation groups tools by learning task.

1. Load the right model family

Keep both diffusion families connected. FL2VA serves compatible text, image and endpoint tasks. REF2VA serves reference-guided and video-editing tasks. The Master chooses the family needed by each clip.

Select the MiniMax text encoder with loader type minimax, the H3 video VAE and the H3 audio VAE. These files live on the ComfyUI server, not merely on your laptop.

An upstream Turbo LoRA/model switch can change the model and its expected step schedule. Keep them consistent. Clip-local LoRAs add their own patches; removing a clip entry cannot undo a patch already present on the input model.

2. Choose a small first test

Use Director Settings for output size, initial steps, sampler and schedule. H3 sampling runs at 24 fps and uses a 32-pixel canvas grid. Both 1280 and 1344 are divisible by 32; they are different valid widths.

A 320 × 192, two-step test checks wiring quickly; it is not suitable for judging final quality. Use your intended model schedule and canvas for a quality comparison. Saved starter values can differ from a newly added node’s defaults.

Keep optional SelfLift, Refine, Face Refine, Semantic Bridge and residual Cache disconnected for a baseline. Keep decoded_output=latest for normal preview work.

3. Prepare inputs, then assign them

Connect loader outputs into Reference Pack. Edit one asset at a time with Edit Reference. Native VIDEO carries its own timing and may carry sound. An IMAGE frame batch needs its source FPS and paired audio supplied separately.

On the Master clip choose the task, then assign only the needed prepared assets. An asset’s role label helps prompt writing; it does not automatically wire an opening/ending frame.

4. Write a focused shot and run

  1. Describe the subject, action, camera and sound. Insert the clip’s current Picture/Video tokens rather than inventing reference numbers.
  2. Choose a short duration, a fixed seed and Independent continuity for the first clip.
  3. Choose Next clip to generate one eligible result, or All clips for the eligible sequence.
  4. Watch the active generation animation, then inspect Latest clip. Approve only a usable result you want reused.

5. Continue deliberately

Add or duplicate the next clip, describe its next action beat and choose a continuity method. Motion Context uses native previous audiovisual guides where compatible. Latent Carry copies a tail with tapered redraw masks. FL2VA Tail Handoff uses a final-frame opening handoff.

Video and audio context are independent: 22 frames is about 0.92 seconds, 24 frames is one second, and 56 frames is about 2.33 seconds at 24 fps. Borrowed context adds work and is removed from delivered new frames.

Duration = new footage describes the visible addition. Duration includes context (Extender) describes the sampling window, so the delivered segment is shorter after prefix removal.

6. Review, reuse and export

The yellow outline selects an editor target. A saved-result indicator means files exist. Approval asks the Master to reuse a result. Unapproving preserves its files and clears continuity-dependent later approvals; successful regeneration replaces the current result.

Smart Preview updates during the run as clips finish. Its Full video scope is separate from Director Settings decoded_output. For a full cached sequence, use Project Video. Video Combine encodes only the frames and audio you feed it.

Words you will meet

Clip
One timeline item.
Latent / VAE
Compressed working data / the encoder-decoder that converts it to and from visible or audible media.
Checkpoint
A completed cached clip here, not a paused sampler state or diffusion model file.
Seed
Starting randomness; one part of a reproducible setup.
Conditioning
Prompt, assigned references and supported continuity guidance.
Refine
Extra processing after the initial generation; it can change the result.
Megapixels
A spatial pixel budget, not duration or a frame-count limit.
Approval
Request to reuse a current available result during generation.
Preview stage
A current result’s first pass or refinement stage, not an older generation.
