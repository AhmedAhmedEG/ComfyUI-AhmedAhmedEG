Understand the flow

Each setting has a home.

Prepare inputs, generate a result, review it, then export it. Change one stage at a time when explaining a difference.

From assets to delivery

Loader nodes→Reference Pack
Prepare inputs→Master + Settings
Assign & sample→Current cache→Preview / export

SelfLift is inside initial sampling. Refine runs after the first pass. Face Refine follows the main result. Pixel Upscale and Frame Interpolation process decoded output. Several stages expose size or strength controls because they perform different jobs.

Current result, approval and replacement

Each clip has one current generation. Its latent, audio, frames and available current stages live on the server. A replacement publishes after saving succeeds, then superseded generation artifacts are removed. Failed replacement saves retain the old usable current result.

Approval asks Master to reuse a result. Unapproval preserves files while clearing later continuity-dependent approvals. Idle preview shows current completed results without requiring approval. During a run, it follows reused results and newly finished replacements instead of presenting queued old results as fresh completions.

Why the same seed can look different

Compare the actual model/LoRAs, attention patches, canvas, steps/sigmas, sampler/scheduler, shifts, effective prompt, asset order and preparation, clip type, continuity method and duration policy. Same prompt and seed alone are insufficient.

Disconnect optional modifiers for a baseline and change one feature at a time. A functional check can prove a setting reaches its processing path; it does not prove aesthetic improvement.

Memory and persistence

Current clip data is disk-backed and working resources are released between stages. decoded_output=latest avoids retaining an unnecessary full raw batch; all current results remain available to cached preview/export. Project Video exports clips in sequence. Browser prebuffering is bounded and best effort.

Workflow JSON stores authoring and links, not every generated latent. Portable reference archives, cache data and exported movies are separate artifacts. A completed checkpoint does not preserve an unfinished sampler’s full state.
