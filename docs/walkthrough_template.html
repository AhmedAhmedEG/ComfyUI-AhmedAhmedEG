01

Get one working video

  1. Drop the starter JSON into ComfyUI. The connections are already made. Your custom nodes are under ComfyUI-AhmedAhmedEG → Start here.
  2. Select the five model files. The two Load Diffusion Model nodes select FL2VA and REF2VA. Load CLIP uses type minimax. The two Load VAE nodes select video and audio VAEs.
  3. Keep the initial settings. Director Settings: 960 × 544, 24 fps, 25 steps, CFG 1, euler / simple, seed 0. Execution: All-in-One Generation; run mode: clip_by_clip.
  4. Edit Shot 1 in the Master. Choose T2V (Text to Video), duration 2 seconds, and Generate for shot audio. Paste the example prompt below.
  5. Click ComfyUI’s Run button. Wait for the shot to complete. Then open the Master’s Preview tab.
A small robot walks through a sunlit greenhouse. The camera tracks beside it. Leaves sway gently. Soft footsteps and birds outside.
You should see: one playable take with sound. H3 rounds generated lengths to its frame grid; a 2-second request becomes 56 frames, about 2.33 seconds.

Both diffusion models are connected, but the Master loads the family needed by your shot. You do not need to swap cables when changing modes.

02

Give the shot something to follow

  1. Choose the mode before adding media. Use I2V for an opening frame, or REF2VA for subject/style/video/audio references.
  2. Expand Upload and edit references on the shot and upload your file. The asset is stored on the ComfyUI server.
  3. Assign it to this shot. Uploading adds it to the pool; assignment chooses which shot uses it. For I2V, set it as the opening frame.
  4. Describe the action. For REF2VA, insert the matching reference token from the prompt buttons, such as <Picture 1>, then explain what that reference should influence.
  5. Run again and compare the new take in Preview → Latest clip.

First/last frames anchor an endpoint. REF2VA references guide content; they are not a frame-by-frame copy.

03

Add the next shot

  1. Keep a take you like. Mark it validated so matching saved results can be reused.
  2. Click + Add Shot. Give Shot 2 its own prompt, duration and references.
  3. Choose the relationship. Independent starts a separate scene. Chained uses the previous take’s tail to guide the next shot.
  4. For a continuation, set an overlap such as 22 frames, then run the next shot. Its generated context prefix is removed from the delivered clip.
  5. Review Latest clip first. Choose Full video only when you want to inspect the join.
Keep generation separate from viewing: Generate selected shots chooses what to compute. Preview chooses what your browser watches. Output chooses what downstream export nodes receive.

Changing a chained shot may invalidate later takes that depended on it. Independent shots can be rerendered separately.

04

Watch less. Export what you mean.

  1. Open Preview → Latest clip. The server prepares a separate file containing only the newest completed shot.
  2. Use Full video to watch the completed sequence. Autoplay starts loaded previews; Save preview downloads the preview file.
  3. For a final sequence, set the toolbar’s Output → Full Video. New/unvalidated or selected output is useful when you deliberately want to export a subset.
  4. Use the starter’s Create Video → Save Video. Create Video receives the Master’s images, audio and fps. Save Video uses the filename prefix minimax/example.
  5. Find the result in your ComfyUI server’s output folder. Standard ComfyUI output/history controls let you download it.

A preview is a lightweight copy, capped at 960 × 540. Final export uses the generated frames at their configured resolution. Switching Preview does not change Output.

If something goes wrong

Missing or UNKNOWN node

Refresh the browser after updating and restarting ComfyUI. Reload the current starter: old graphs may contain removed wrapper nodes.

The shot fails before sampling

Check the FL2VA/REF2VA selection, CLIP type minimax, both VAEs and the shot’s assigned references. Check dimensions and reference limits.

Out of memory

Shorten the shot or reduce resolution first. Then consider SelfLift, spatial tiles or temporal chunks. A text encoder can also consume substantial memory.

Preview or project export is empty

Generate a completed take first. Restore the cache and source assets if you moved machines. A workflow JSON does not contain the generated video.

Files and models live on the ComfyUI server. Workflow JSON saves the graph; portable project archives carry reference/source assets, but not models or heavy generated takes. Back up those separately.
