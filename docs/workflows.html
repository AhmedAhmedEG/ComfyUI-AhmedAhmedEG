Continue an action

Set it up

Keep the first clip’s settings as a baseline. On the next clip choose Motion Context, a short video context and an independent audio context. Use New footage duration for the intended visible addition.

Check the result

Inspect the seam, action and sound. More context adds work; it cannot guarantee exact choreography. Latent Carry is a different masked-prefix method, not a stronger setting of Motion Context.

Reduce reference video cost

Set it up

Select the video in Reference Pack → Resize → Megapixels. Start with 0.5 MP. Choose Video Only to exclude the soundtrack or Video + Audio when both belong in conditioning.

Check the result

The pack prepares pixels before native reference encoding. It follows aspect ratio and alignment without enlarging smaller sources; output canvas remains a separate Director setting.

Inspect first, refine later

Set it up

Connect Refine and enable Confirm First Pass before generating. Review the first pass, approve that stage on its timeline card, then run again. Use global to retain its audio.

Check the result

A matching staged first pass is reused. Ten completed initial steps plus fifteen refinement steps are not a twenty-five-step initial schedule. Persistent exact sampler resume is not exposed.

Compare SelfLift fairly

Set it up

Generate a baseline with SelfLift disconnected. Keep seed, prompt, assets and target canvas unchanged, then connect SelfLift with a learned H3 latent upscaler and choose the low/high-resolution split.

Check the result

Compare faces, hands, action, detail and runtime. A smaller early canvas changes the sampling path; it does not guarantee equivalent or better quality.

Use a LoRA on one clip

Set it up

Open that clip’s LoRAs tab. Add an enabled compatible H3 patch and set its model strength. Keep other variables fixed.

Check the result

Check upstream model patches too. A globally patched input and a clip-local patch can both apply. Same seed alone is not a controlled comparison.

Draft several shots

Set it up

Configure a Prompt Forge provider. Request a small number of focused shots and review its proposal before append/replace.

Check the result

The output is text, not rendered video. Roles/cast help writing; clip asset assignment separately owns video model conditioning. External providers receive submitted context.

Export all current clips

Set it up

Connect Master.project_state to Project Video. Choose final, all and the correct FPS. Enable individual shot files if needed.

Check the result

Readable cached media can export without new diffusion. decoded_output=latest does not remove the other cached clips. Exported files remain separate from automatic cache replacement.

Open the node chapter →

Reduce an audible join

Set it up

Inspect the generated soundtrack and per-clip Audio Context first. Use project Join Fade for waveform clicks and gain matching for loudness jumps.

Check the result

Fading cannot make unrelated music, changed voices or different ambience semantically continuous. Audio Context affects generation; Join Fade affects assembled output.
