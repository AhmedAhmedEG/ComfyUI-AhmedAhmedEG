External timeline ownership

Connect Image To Video Group or Reference To Video Group outputs to Groups Combine, then connect the combined groups to Timeline Builder. The typed timeline output connects to Master.timeline. This restores external graph authoring without adding competing group configuration panels to the Master. Each group receives a stable identity from its ComfyUI node ID. Prompt, duration, type and the actual media tensors are authored by the group nodes. The Master retains execution controls such as seed, continuity and take approval against those identities.

Running the graph resolves the authored sequence and reports a sanitized timeline snapshot to the Master editor. Tensor data is not placed inside workflow JSON. The editor disables fields that the connected builder owns. Disconnect the builder to resume local authoring; review the visible timeline first. Reordering groups changes sequence order, while changing a prompt updates the existing clip rather than assigning it a new random identity. Duplicate identities are rejected because they could map two clips onto the same cached take.

The authoring_json output is a readable metadata export. It cannot reconstruct procedural IMAGE or AUDIO tensors by itself. Preserve the original workflow for those connections. Approved takes keep their normal immutable cache semantics; a builder is not a command to replace an approved take. Clear approval before deliberately generating a changed authored clip. Use one builder for a Master, with one ordered combined group list. This node does not sample, load diffusion weights, or join output video.
