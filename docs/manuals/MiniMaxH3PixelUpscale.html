Upscale visible frames after VAE decoding

Pixel Upscale accepts an IMAGE batch and returns resized RGB frames. It is a post-decode stage, separate from SelfLift and latent Refine. Connect Master.images or cached frames to its input, then send the result to your saver while carrying the original matching audio/FPS alongside it. This node itself has no AUDIO input/output and does not change the number of frames.

Which controls apply to which provider

width/height are the exact target pixel dimensions. Bicubic and learned_pixel directly resize to this shape; they do not honor the RTX aspect-fitting selector. Thus a target aspect ratio different from the input can stretch these paths. Choose dimensions with the intended aspect ratio before blaming a model for stretched faces.

resize_method controls the RTX fitting path: Center Crop (Fill) fills the target canvas while cutting excess edges; Letterbox (Fit) preserves the whole frame and can pad unused space. quality sets the supported RTX effect quality. denoise/deblur request optional preprocessing SDK effects before the main RTX enhancement. They do not change bicubic interpolation or activate a diffusion refine pass.

upscale_model is required for learned_pixel and unused by plain bicubic/RTX. It must be an RGB UPSCALE_MODEL, not an H3 latent-upscale filename. A missing model raises an explicit error. An unavailable CUDA/SDK effect is a dependency failure; the node does not silently pretend RTX enhancement occurred.

Memory, temporal consistency and a first comparison

The node iterates SDK frames but still creates an output batch, so large dimensions/long clips can use substantial host memory. Learned image upscalers can treat neighboring video frames independently and introduce texture flicker. Enlarging a frame creates more pixels, not proof of newly correct detail.

  1. Start with one short shot at its original size.
  2. Try bicubic at a matching aspect ratio, such as 1920×1088 for 960×544.
  3. Try a stock loaded image-upscaler MODEL via learned_pixel with the same target. Compare edges and frame-to-frame texture.
  4. Only select an RTX provider when its SDK is installed and tested. Keep FPS/audio unchanged downstream.
