An LLM drafts authoring data; H3 generates the movie

Prompt Forge sends a timeline context and your instruction to a selected language-model provider, parses its answer into a constrained shot draft and returns that draft for review. It does not call the video sampler, validate a generated take, connect references or automatically apply the answer to the Master. Connect its draft to Review / Apply Prompt Draft. Drafting and review are configured only in these connected nodes.

timeline is current authoring JSON. instruction describes the shots you want drafted. shot_count requests an exact number from 1 to 100; it is neither seconds nor model context length. The system request asks for JSON with prompt, duration and type fields while preserving supplied context/reference identities. A model can still fail the requested format; parsing/validation is mandatory.

endpoint is evaluated on the ComfyUI server. On a remote installation, localhost:11434 means the remote host/container, not your laptop. For a compatible service whose base includes /v1, enter that base; the implementation appends /chat/completions. model_name must be a provider-known name, not the H3 diffusion checkpoint. The HTTP path uses a timeout and propagates provider/format failures.

Optional images supplies up to twelve IMAGE frames for a vision-capable provider. The node clamps pixels, converts to PNG, limits image size to 1024 and sends base64 image content in the backend's supported message shape. Selecting a text-only LLM does not make it understand images. Supplying images to an external provider transmits those images to that configured endpoint; this node is not merely inspecting them locally.

Draft contract and restrictions

{
  "context_key": "fingerprint of the supplied timeline context",
  "count": 2,
  "shots": [
    {"prompt": "A person walks toward the window", "duration": 5, "type": "T2VA"},
    {"prompt": "The person turns back toward camera", "duration": 5, "type": "T2VA"}
  ]
}

The parser normalizes supported task aliases, checks finite valid durations and checks exact shot count. It accepts only authoring fields prompt, duration and type. A response cannot invent file paths, alter ref_ids, unlock a source clip, select an arbitrary checkpoint/model override or mark a take validated. Those fields belong to explicit project authoring and execution, not model-generated authority.

draft is MMX_PROMPT_DRAFT for the apply node. review_json is a readable STRING representation for inspection. They are not CONDITIONING or finished video. The context_key permits the apply step to reject a draft based on an older/different timeline.

Drafting two shots without losing references

  1. Supply the current timeline and an instruction such as “Draft two five-second shots of the same person approaching a window; maintain appearance and soft room ambience.”
  2. Set shot_count 2 and select a working provider. Test a small draft before a long storyboard.
  3. Read review_json: inspect task types, duration and reference-token text.
  4. Apply only after review. Replace preserves relevant existing per-shot assets/overrides for matching positions; Append carries applicable reference assignments into fresh clip identities.

If a draft fails, inspect HTTP reachability, model availability and the returned JSON before blaming H3. If a reference is absent from supplied context, do not assume the provider can know it from an unrelated pool name. The apply-stage context check and explicit reference assignment remain necessary.

Dedicated draft review panel

Choose a Master in the Forge panel and Create Draft. Review its JSON before Apply Reviewed Draft. The panel keeps three drafts in workflow properties, accepts a session-only password field, and optionally sends file-backed reference pictures. Native images/generator inputs remain the graph path for procedural tensors or custom providers. Creativity changes provider temperature and requested variability; Detail changes descriptive precision without adding clips. shot_descriptions is an ordered JSON instruction list. Existing clip types cannot be changed by replacement; append new clips instead.

Cancel Request aborts the browser request and prevents a late response from being applied. Local token generation receives a stop signal and remote streaming connections are closed. Remote services can continue computing after disconnect. Apply checks that the source timeline context still matches. A connected Timeline Builder owns authoring, so the panel rejects writing competing edits into that Master. The legacy graph Review / Apply node remains available for workflows that consume drafts as data; use one apply path.

Compatibility and ownership in 1.6

Per-clip instruction text boxes replace raw description-array editing. Continuation Clip reads chronological predecessor frames from the saved project and rejects stale takes during Apply. The HTTP editor refuses drafting during active generation. Cast/retention metadata is owned by Reference Pack; Forge compiles clip-local labels without renumbering ignored writer references. Request cancellation prevents applying a late response; remote computation may continue when its provider has no cancellation API. Ollama requests specify keep_alive=0.

Compiled native label mappings are saved by reference identity. Runtime reorders tags when those identities move slots and rejects missing mapped references. Manual prompt edits end automatic remapping for that prompt.

Reviewed cast appearance cards

Cast Appearance Cards edits one character, place, style or pose at a time. Refresh discovers cards from images assigned to timeline clips. Read Card From Pictures reads just the matching selected images. Isolated people use their boxes with a small margin; substantially overlapping boxes are read from the full picture with the target position. Pose cards describe stance without transferring identity. Review the text and click Use Reviewed Description. Generated text never silently replaces a saved card.

Reviewed descriptions persist in the project and portable export. They define appearance in reference-mode subject definitions and reach keyframe-mode writing as ordinary prose. Changing cards invalidates an older draft's context. No reference-selection controls are duplicated here.

Imported Prompt History holds text recovered from foreign files. Prepare Imported Prompt For Review creates a fresh review proposal without applying it or declaring historical reference labels verified. Check tags and Apply Policy before using Apply Reviewed Draft.
