Resolution, sampling and reproducibility

width and height define the generation canvas. H3's video VAE reduces spatial dimensions by 16 and the transformer patchifies 2×2 latent cells, so the canvas uses multiples of 32. A 960×544 frame contains 510,240 pixels; 1344×768 contains 1,032,192, approximately twice as many. Increasing both dimensions by a factor of two creates four times as many pixels, although exact memory and runtime depend on attention, frame count and model offloading.

frame_rate is fixed to 24 for H3 generation. Changing an encoder's FPS later does not change the time basis of reference guides. Use Output Processing for a deliberate resample or retime. Requested durations are aligned to 5 + 17k frames; for example, 48 requested frames become 56, or about 2.333 seconds, in the standard upward alignment path.

steps counts diffusion sampling iterations. It is not the clip duration. Use the step schedule intended for the selected model/LoRA; the starter's Boolean drives a stock integer selector, choosing 25 base steps or 8 Turbo steps through this node's connected steps input. Edit the two integer nodes to change those presets. A connected input is authoritative even if the disabled widget still displays a saved fallback value. This is a global step choice; turn Turbo off when running a family for which that LoRA is not intended.

cfg controls classifier-free guidance passed to the sampler. The starter uses 1. A larger number does not mean higher resolution or guaranteed stronger adherence; it changes the balance of conditional/unconditional guidance and can create artifacts. sampler chooses the numerical integration method and scheduler chooses the noise schedule. Their choices come from installed ComfyUI. Keep euler/simple while establishing a baseline. If external SIGMAS are connected to the Master, that supplied schedule takes precedence in the sampling path; do not treat a dropdown change as proof that the external schedule changed.

shift_video and shift_audio are separate H3 noise/sigma shifts. They alter the audiovisual sampling schedule; they are neither audio volume nor a time offset. The standard starter uses 12 and 3. Changing them changes the effective generation inputs and may invalidate a take. seed initializes sampling noise. Keep it fixed for comparisons, but also keep model, references, conditioning, algorithm and dimensions fixed: a seed alone does not reproduce a result across arbitrary changes. Per-shot seeds and seed-advance behavior can override the baseline.

Configuration precedence and an external-input example

settings_optional carries a previous configuration. This node copies it and overwrites matching fields with its own canvas/sampling values, retaining other incoming keys. The Master uses the resulting config as its baseline; per-clip generation options affect their own clips; canvas policy is configured only here. SelfLift, Refine and FaceRefine are separate configuration packs connected to their own Master sockets.

PrimitiveBoolean: Enable Turbo ─┬─→ model selector: base / LoRA ─→ REF2VA attention ─→ Master
                               └─→ INT selector: 25 / 8 ─→ Director Settings.steps
Director Settings.config ───────────────────────────────────────────────────────────→ Master.config

To connect a different external integer in your own graph, convert the steps widget to an input using ComfyUI's widget context menu, then connect an INT output. Removing the connection restores ordinary widget use. Do not connect the Boolean itself to an INT steps input.

Where Generation and Continuity controls live

Director Settings contains canvas and sampling settings. Generation mode is now the prominent labeled dropdown in the Master, above the timeline. Select a clip to edit its Continuity section: method, video context, audio context and latent seam redraw. These controls are no longer global widgets in Settings. The starter and saved-workflow migration transfer the previous values into the connected Master's state.

If connected steps looks disabled, the integer selector cable controls it. An outdated browser can still display the old Settings definition; save the graph and hard refresh after installing the update. The new Master Generation bar is the authoritative execution control. Optional features are grouped in large labeled sections; expanding them reveals descriptions and labeled fields.

Implementation: node_settings.py, node_director.py, continuity.py, latent continuation.

Canvas policy has one owner

Choose Manual to use this node’s width/height. Original derives width/height from usable imported source or Reference Pack media, rounded to the H3 spatial grid. Auto computes a canvas from canvas_megapixels and canvas_aspect. One megapixel means roughly one million pixels; 16:9 determines their shape, not video duration. Auto aspect follows source dimensions and requires available media. The megapixel and aspect fields affect Auto only; the numeric width/height fields affect Manual only. These are alternatives within this node, not competing settings in the Master.

For example, Manual 960×544 uses about 0.51 MP. Auto 1 MP at 16:9 requests roughly twice the pixel count before spatial rounding. Original with a portrait source keeps its source proportions; it may need substantially more memory than the starter. Keep Manual for a predictable first render. Imported legacy Master canvas controls migrate into connected Settings; current Settings policy wins over old timeline fields during execution.
