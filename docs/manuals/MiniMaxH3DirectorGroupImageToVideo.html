A shot description built from graph inputs

This is an advanced alternative to typing every keyframe shot inside the Master. It packages a prompt, duration and optional first/last pictures into MMX_DIR_GROUP. It does not sample video and does not load a diffusion model. Connect its output directly to Master.i2v_groups, or combine several group outputs first.

prompt is the group's shot text; duration_sec is requested visible time. H3 generation still aligns frame count, so a 5-second request is not a promise of exactly 120 sampled frames. first_frame/last_frame are IMAGE objects, not filenames. Their connection pattern selects the group's task.

What the pack contains and how it is consumed

{"family":"i2v", "kind":"fl2v", "prompt":"A door slowly closes",
 "duration_sec":5.0, "first_frame":IMAGE, "last_frame":IMAGE}

The family key names the graph group channel, not a separate model architecture. These keyframe tasks use FL2VA in the Master. The frames constrain endpoints; the text describes the movement between them. Images that imply incompatible geometry or a very large scene transition can produce an unstable interpolation even when the graph is valid.

For an endpoint experiment, connect Load Image A to first_frame, Load Image B to last_frame, set five seconds and describe one simple movement. Connect a compatible FL2VA model and both audiovisual VAEs to the Master. Use All shots when you intend to process a group list in one execution. The group is authoring data; do not send it to a Save Video node.

Ordinary editor reference authoring uses Reference Pack. These group nodes deliberately carry their own per-shot graph assets for advanced programmatic graphs; they do not add individual reference upload inputs to the Master. Avoid maintaining two conflicting descriptions of the same shot through editor and group inputs without understanding how the supplied groups map to the Master timeline.
