Library selection and ownership

The library lists installed RefMod files and gives each selected item its own identity, description and strength. Connect its library output to Reference Pack.refmod_library. The pack exposes these items to the Master as selectable reference identities. The Master still decides which identities belong to a clip; editing their descriptions and strengths belongs here. A zero strength is a deliberate zero contribution rather than a missing selection. Strength must remain between zero and four.

Refresh Library reads the server catalog. Use RefMod selects a row, Description records identity guidance, and Strength sets the model contribution. These choices are serialized in library_data with the workflow. Reloading a workflow restores the selected rows rather than silently selecting every installed adapter. Names refer to installed files: this library does not download weights or train RefMods. The runtime resolves the file when a generated clip actually uses it and reports missing files as errors.

Stable IDs avoid merging different characters merely because their descriptions are similar. Duplicate IDs are rejected. Connected libraries append their entries to a Reference Pack with the pack namespace, allowing packs to be combined safely. If a selected file is removed from the server, refresh the catalog and repair that selection before generation. Identity strength is distinct from a diffusion LoRA strength. The library output contains descriptors only; loading and applying the requested adapter happens during conditioning of the selected clip. Keep character descriptions precise and do not assign unrelated subjects the same identity.
