Review authoring conversion before use

This converter reads supported authoring metadata from current timelines, DaSiWa reference packs, AIMixer timeline lists and Tritant Extender projects. The panel accepts JSON or a project ZIP/EXT archive, then Convert And Review displays a converted timeline and warnings. Apply Converted Timeline updates a chosen local Master only after review. Alternatively, connect the typed timeline output to Master.timeline to keep the converter as its authoring owner. Do not use both authoring paths for the same Master.

Converted clips receive deterministic identities based on the source metadata and index. Repeated conversion of identical metadata produces the same identities. Approval is reset: an upstream validated flag does not establish that this package has a readable final take. Model weights, foreign latent files and sampler settings are not imported into execution. Reconfigure the Settings and model loaders, then generate new takes or use decoded video footage from the Reference Pack. The report explicitly states that caches were not imported.

Archive paths are checked before any media extraction. Absolute paths, parent traversal and unsupported archive structure are rejected. Supported embedded media is copied into a content-namespaced directory beneath the server input folder; it is not copied into the model folders. Missing media is listed in the report. JSON conversion alone cannot transfer files from another machine. AIMixer conversion requires an explicit clip, segment or group list, and unsupported rich fields require manual review. This is a metadata migration tool, not binary compatibility with every historical project serializer. Preserve your original archive and inspect prompts, media assignments and durations before running a model.
