Change detection and completeness

The loader tracks the current latent file modification time and requires readable latent, frames and audio. Workflow JSON alone does not restore server cache files.

This checkpoint contains a finished generation, not an unfinished noisy latent with schedule position and sampler history. Refining a completed ten-step clip for fifteen steps is not equivalent to generating it with twenty-five steps from the start.
