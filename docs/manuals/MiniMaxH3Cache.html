Approximation within a sampling run

This node clones/patches a compatible MiniMax H3 MODEL so selected diffusion steps can reuse a previously computed transformer block-stack residual. The input signature is compared with the previous signature; when the reuse conditions pass, the stack's expensive work can be skipped and its residual applied to the current state. Sampling-scope wrappers reset the transient cache, and changes to layout/timestep conditions prevent unsafe reuse across incompatible sequences.

This is distinct from the Master’s disk take cache. An approved disk take can avoid an entire new diffusion sample. Residual Cache approximates computation inside a sample that still runs. It neither validates timeline shots nor restores an MP4 from a previous project.

When reuse is permitted

reuse_threshold bounds the relative signature change used by the heuristic. Higher thresholds accept more approximate reuse; lower thresholds are more conservative. start_percent/end_percent restrict reuse to part of the sampling-progress interval, expressed as 0–1 fractions. Start must not exceed end. Excluding early/late steps can retain important structure/final-detail computation.

max_steps limits consecutive reuse before recomputation. device chooses auto/cuda/cpu storage policy for the cache; CPU storage can reduce retained GPU data but adds transfers. verbose emits diagnostic information, not a quality improvement. The returned MODEL carries the patch; you must wire it into the active family/model override, not leave it beside an unpatched parallel cable.

Quality and compatibility checks

Begin with a fixed seed and a short scene. Compare the unpatched model with threshold 0.05, interval 0.15–0.90 and max_steps 2. Inspect moving limbs, camera motion and fine texture for ghosting/temporal smearing. A faster execution is not a valid win if the motion is damaged. For maximum fidelity, bypass the patch.

The implementation inspects the diffusion model and expects MiniMaxH3Model with a block stack and supported patch/wrapper contracts. It can reject another architecture even though that input has type MODEL. It replaces parts of the forward path; other attention/forward modifiers need compatibility checking. No fixed 1.5× or 2× speedup is guaranteed on your hardware or shot.

Implementation: H3BlockStackCache and sampling-scope wrapper.
