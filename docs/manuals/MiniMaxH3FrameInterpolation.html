Time, endpoints and provider requirements

This output node accepts an ordered decoded IMAGE batch, its playback FPS and optional AUDIO. It returns a longer IMAGE batch, fitted audio and the faster FPS. Connect all three outputs to an encoder. A multiplier of two doubles FPS and frame count, preserving the container duration. Source endpoints are retained. Extra copies of the last source frame preserve its final frame hold; otherwise the usual pair interpolation formula would shorten the encoded container by part of a frame interval.

Linear is a CPU-compatible pixel blend fallback. It does not estimate optical flow, and objects may look like a dissolve between source frames. Detect Cuts uses a conservative mean pixel difference threshold of 0.3 on normalized image data for this fallback. When the threshold is crossed it holds the previous frame rather than blending across the cut. RTX delegates pair interpolation and automatic cut detection to the NVIDIA SDK. LOW, MEDIUM and HIGH are SDK quality presets; they only affect RTX. No fixed quality or speed guarantee follows from those names.

RTX needs a supported GPU, working SDK dependencies and compatible drivers. Selecting it without those dependencies fails explicitly. It is never silently substituted with Linear. Images need at least two frames. Multiplier is between two and eight and source FPS between one and 120. The node keeps or fits audio to the resulting duration; it does not generate speech or stretch the sequence into slow motion. Changing source FPS changes playback duration, so use the actual source rate. GPU execution and visual motion quality require validation on the target installation.
