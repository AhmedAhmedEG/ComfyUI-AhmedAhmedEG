01 / The connections

Give the Master
its ingredients.

The starter has five nodes and one model loader. Its connections are already in place.

  1. Model Loader: select FL2VA in the starter. For reference/source modes, use the consolidated example and its REF2VA connection.
  2. Encoder Loader: select the Qwen MiniMax text encoder, video VAE and audio VAE. Connect all three to Master.
  3. Director Settings → config. Master images + audio → Video Combine.

Replace every SELECT… filename with a model installed on your ComfyUI server.

Installing or getting a model error?
Install in ComfyUI/custom_nodes, install requirements using ComfyUI’s Python and restart. ComfyUI needs native H3 generation, AddGuide, SigmaShift and current VIDEO APIs. Models and output files live on the server.
02 / Your first shot

Describe one
thing happening.

Try the green workspace, then do the same in your actual Master Node.

  1. Add a T2VA shot. Describe action, camera, scene and sound.
  2. Choose a short duration, a canvas divisible by 32 and a fixed seed. Start with independent shots.
  3. Queue in ComfyUI. Inspect the take, then change one setting and rerun.

A 5-second request becomes 124 frames: about 5.17 seconds. H3 uses 24 fps and the 17k + 5 frame grid.

Other generation modes?
I2VA: opening image. FL2VA: opening + closing images. L2VA: closing image. REF2VA: image/video/audio references. V2V/RV2V: source edits. Image Inpaint: one generated still.
03 / Show what you mean

Give a shot
something to follow.

An opening image sets the first frame. A reference guides content.

  1. Upload/drop media into the Master’s pool; select it for the shot.
  2. Crop the useful region; trim video/audio start and end. Choose video, audio or both.
  3. Choose the mode and add reference mentions with the editor. Check resolved_prompt.

Try selecting the sample image and switching modes in the workspace.

RefMods, LoRAs and media limits
Up to 9 images, 3 videos, 3 audios, 12 combined. Reference videos total ≤15 seconds. RefMods bundle media; LoRAs modify model weights. RefMod details →
04 / Build a sequence

A shot becomes
a story.

Each shot has its own prompt, references, duration and seed.

  1. Generate shot 1 and approve the take you want to keep.
  2. Choose independent scenes or chain the next shot from the previous take’s tail.
  3. Generate the next shots; inspect transitions. Continuity prefixes are trimmed from visible output.

Toggle continuity in the workspace. Changing a chained shot can invalidate later takes.

Editing a source video instead?
Load a source, split ranges, regenerate selected ranges with V2V/RV2V, and keep others as source passthrough. Use locked source Clip 0 to extend a video. Source editing →
05 / Optional improvements

Choose the stage
you want to change.

Add one enhancement and compare with the same take and seed.

  1. SelfLift: sample small, then finish at higher resolution.
  2. Refine: another latent pass. FaceRefine: track and regenerate one face crop.
  3. Pixel / RTX: enlarge frames after Master. Keep audio connected separately.

Tap a tool in the workspace to see where it runs.

Memory, Semantic Bridge and Cache
Tiles/chunks reduce memory. Semantic Bridge adapts conditioning. Model Cache reuses computation; saved-take cache stores results. Bridge and Cache →
06 / The finished file

Save the picture
and the sound.

Video Combine saves current IMAGE/AUDIO. Project Video assembles cached shots.

  1. Master images + audio → Video Combine. Start with MP4/H.264.
  2. Match FPS, set filename prefix and enable save_output.
  3. For a whole project: project_state → Project Video. Choose final, pre-refine or original-source.

Playback / Watermark / Loop goes before the exporter. Resample preserves duration; retime changes speed and pitch.

Save the project as well
Workflow JSON stores wiring. Project JSON stores authoring. .mmxproj includes reference/source bytes, not models or heavy generated takes. Project formats →
