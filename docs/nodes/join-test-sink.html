Join Test (internal)

Internal helper for the Master editor's Test join button. You never add or wire this node yourself; the editor adds it to a temporary prompt and it does not appear in the node menu.

Use it when: Lets a join test run only the Master node and the nodes that feed it. ComfyUI runs a prompt only when it ends in an output node, so the editor connects this sink to the Master's status output instead of your save, preview or combine nodes. Because none of those run, a join test writes no video, image or audio files and leaves your saved takes untouched.

1. What it does

Only the opening second after the reused context is sampled with the clip's own seed, settings and noise; its colour and brightness at the join are measured and shown, and nothing is saved as a take.

2. Connect it

Master status → status (added automatically by the editor for a Test join run)

3. First use

  1. Open a clip that continues the previous clip in the Master editor.
  2. Make sure every clip before it has a saved take.
  3. Press Test join in the Continuity tab; the editor queues the temporary prompt with this sink.
  4. Read the Join row in the Measured card, calibrate if needed, and test again before generating the full clip.

5. Practical examples

Use case 01

Check a join before generating the whole clip

Set it up
Continuity tab → Test join on a continuing clip whose earlier clips are saved.
Expect
Only the opening second after the reused context is sampled with the clip's own seed, settings and noise; its colour and brightness at the join are measured and shown, and nothing is saved as a take.

6. What comes out

This output/display node has no output sockets; its connection schedules upstream work.

7. Limits & troubleshooting

  • This node only receives the Master node's status text and returns nothing.
  • If it appears in an old workflow you can delete it; the editor adds it again when needed.
  • A join test needs the earlier clips to be saved already, because it continues from them exactly as the full run would.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
