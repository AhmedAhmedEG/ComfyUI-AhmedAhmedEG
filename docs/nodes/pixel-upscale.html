Pixel / RTX Upscale

Resize decoded pictures using interpolation, a learned image model or optional RTX effects.

Use it when: Change delivery dimensions after generation without running H3 diffusion refinement.

1. What it does

Frames are resampled; no new diffusion steps or semantic detail guarantee.

2. Connect it

Decoded IMAGE batch → images
Optional UPSCALE_MODEL → upscale_model
resized images → encoder

3. First use

  1. Choose bicubic/lanczos for ordinary resizing or a learned/RTX provider with its required dependency.
  2. Set width/height and aspect handling.
  3. Enable denoise/deblur only on a supported RTX path.
  4. Compare texture, edges and temporal stability before exporting.

Bicubic/lanczos resampling, learned image upscaling or supported NVIDIA RTX effects.

Use ordinary resampling for a simple resize; learned/RTX only with their dependencies.

Type: COMBO · Initial value: bicubic · Required

bicubic
Ordinary smooth pixel resize without learned enhancement.
learned_pixel
Run the connected learned image upscale model, then fit the target size.
RTX VSR
Use supported NVIDIA video super resolution; SDK/runtime required.
RTX High Bitrate
Use the supported NVIDIA high-bitrate enhancement route; SDK/runtime required.
lanczos
Ordinary edge-preserving resampling; inspect ringing.

resize_method

Setting

How to handle a source and target with different aspect ratios.

Use it when
Stretch fills by distortion; Center Crop fills by removing edges; Letterbox fits with padding.
What changes
Determines framing during pixel preparation or resizing.
Keep in mind
Cropping can remove subjects; stretching can change their proportions.
Choices, defaults & connection details

Type: COMBO · Initial value: Center Crop (Fill) · Required

Center Crop (Fill)
Fill the target without stretching by cropping edges.
Letterbox (Fit)
Keep the whole image inside the target with padding.
Stretch
Fill the target by changing proportions.

7. Limits & troubleshooting

  • RTX requires the supported NVIDIA SDK/runtime and GPU. It is not available merely because CUDA exists.
  • Postprocessing output size differs from Reference Pack input size and Director Settings generation canvas.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
