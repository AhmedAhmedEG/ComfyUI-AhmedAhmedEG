MiniMax H3 Pixel / RTX Upscale and Refine

Resizes decoded frames with bicubic, learned image upscaling or optional NVIDIA RTX effects.

Enhancements1 output

Use it when: Use it after generation when you need larger pixel output.

In plain language

This enlarges finished pictures after they have been decoded. Bicubic is a conventional resize; learned upscaling uses an image-upscale model; RTX effects need the supported NVIDIA software and hardware.

Your first use: Connect Master images. Start with bicubic and a modest scale to verify the graph. Send the resized frames to Create Video and keep the Master’s audio connected separately. This node returns pictures, not sound or a finished video file.

Connections

Master images → images; IMAGE output → Create Video images
Master audio + fps → Create Video audio + fps

How it works

  • bicubic resizes directly. learned_pixel first invokes an UPSCALE_MODEL, then resizes to the exact width and height.
  • Those two paths can stretch the aspect ratio; resize_method applies to RTX providers.
  • RTX paths require CUDA and the optional NVIDIA effects runtime. They can run denoise/deblur before the chosen VSR or High Bitrate effect.
  • Returns processed IMAGE frames only. Audio and timing are passed separately to the exporter.

How to use it

  1. Connect Master images to images.
  2. Start with bicubic and a target matching the original aspect ratio.
  3. For learned_pixel, connect a stock-loaded UPSCALE_MODEL.
  4. Send output frames to Create Video while keeping the original Master audio and fps connections.

Limits and troubleshooting

  • This operates on pixels, not the H3 latent. Learned image weights do not belong in Refine’s latent_upscale_model selector.
  • RTX settings have no effect on bicubic/learned_pixel paths. Missing RTX dependencies or hardware produce an error.
