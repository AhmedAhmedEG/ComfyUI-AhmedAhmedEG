MiniMax H3 Pixel / RTX Upscale and Refine

Resizes decoded frames with bicubic, learned image upscaling or optional NVIDIA RTX effects.

Enhancements1 output

Use it when: Use it after generation when you need larger pixel output.

In plain language

This enlarges finished pictures after they have been decoded. Bicubic is a conventional resize; learned upscaling uses an image-upscale model; RTX effects need the supported NVIDIA software and hardware.

Your first use: Connect Master images. Start with bicubic and a modest scale to verify the graph. Send the resized frames to Create Video and keep the Master’s audio connected separately. This node returns pictures, not sound or a finished video file.

Connections

Master images → images; IMAGE output → Create Video images
Master audio + fps → Create Video audio + fps

Upscale visible frames after VAE decoding

Pixel Upscale accepts an IMAGE batch and returns resized RGB frames. It is a post-decode stage, separate from SelfLift and latent Refine. Connect Master.images or cached frames to its input, then send the result to your saver while carrying the original matching audio/FPS alongside it. This node itself has no AUDIO input/output and does not change the number of frames.

providerOperationRequirements
bicubicSpatial bicubic interpolation to width/height, with clamping to [0,1].No learned upscaler or RTX SDK.
learned_pixelRuns ComfyUI's ImageUpscaleWithModel, then bicubic-resizes to the exact requested dimensions.Connect a compatible UPSCALE_MODEL from a stock image-upscaler loader.
RTX VSRRuns the optional NVIDIA video-super-resolution effect on each frame.NVIDIA CUDA GPU, supported nvvfx SDK/bindings and effect availability.
RTX High BitrateUses the optional SDK high-bitrate enhancement path.Compatible NVIDIA SDK and GPU.

Which controls apply to which provider

width/height are the exact target pixel dimensions. Bicubic and learned_pixel directly resize to this shape; they do not honor the RTX aspect-fitting selector. Thus a target aspect ratio different from the input can stretch these paths. Choose dimensions with the intended aspect ratio before blaming a model for stretched faces.

resize_method controls the RTX fitting path: Center Crop (Fill) fills the target canvas while cutting excess edges; Letterbox (Fit) preserves the whole frame and can pad unused space. quality sets the supported RTX effect quality. denoise/deblur request optional preprocessing SDK effects before the main RTX enhancement. They do not change bicubic interpolation or activate a diffusion refine pass.

upscale_model is required for learned_pixel and unused by plain bicubic/RTX. It must be an RGB UPSCALE_MODEL, not an H3 latent-upscale filename. A missing model raises an explicit error. An unavailable CUDA/SDK effect is a dependency failure; the node does not silently pretend RTX enhancement occurred.

Memory, temporal consistency and a first comparison

The node iterates SDK frames but still creates an output batch, so large dimensions/long clips can use substantial host memory. Learned image upscalers can treat neighboring video frames independently and introduce texture flicker. Enlarging a frame creates more pixels, not proof of newly correct detail.

  1. Start with one short shot at its original size.
  2. Try bicubic at a matching aspect ratio, such as 1920×1088 for 960×544.
  3. Try a stock loaded image-upscaler MODEL via learned_pixel with the same target. Compare edges and frame-to-frame texture.
  4. Only select an RTX provider when its SDK is installed and tested. Keep FPS/audio unchanged downstream.

Implementation: provider dispatch and resize semantics, optional SDK adapter.

Execution summary

  • bicubic resizes directly. learned_pixel first invokes an UPSCALE_MODEL, then resizes to the exact width and height.
  • Those two paths can stretch the aspect ratio; resize_method applies to RTX providers.
  • RTX paths require CUDA and the optional NVIDIA effects runtime. They can run denoise/deblur before the chosen VSR or High Bitrate effect.
  • Returns processed IMAGE frames only. Audio and timing are passed separately to the exporter.

How to use it

  1. Connect Master images to images.
  2. Start with bicubic and a target matching the original aspect ratio.
  3. For learned_pixel, connect a stock-loaded UPSCALE_MODEL.
  4. Send output frames to Create Video while keeping the original Master audio and fps connections.

Limits and troubleshooting

  • This operates on pixels, not the H3 latent. Learned image weights do not belong in Refine’s latent_upscale_model selector.
  • RTX settings have no effect on bicubic/learned_pixel paths. Missing RTX dependencies or hardware produce an error.
