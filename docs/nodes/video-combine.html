Video Combine & Audio Muxer

Encode supplied frames and audio into a video file.

Use it when: Save a raw IMAGE batch, or use codec and audio encoding controls.

1. What it does

Only those supplied frames are encoded, regardless of how many clips exist in the project.

2. Connect it

IMAGE batch → images
AUDIO → audio
Matching frame rate → frame_rate

3. First use

  1. Connect the frames you actually intend to encode and their matching audio.
  2. Choose codec/container and an available encoder backend.
  3. Choose quality and save_output, then set a server-relative filename prefix.
  4. Run and inspect the file. Use Project Video if the raw Master output is only the latest clip.

Save just the latest clip

Set it up
Use Master decoded_output=latest and feed its IMAGE/AUDIO outputs here.
Expect
Only those supplied frames are encoded, regardless of how many clips exist in the project.
Use case 02

Export a full sequence

Set it up
Use Project Video for all cached clips, or explicitly request a full raw frame batch.
Expect
Video Combine cannot infer additional project clips from a partial IMAGE input.

7. Limits & troubleshooting

  • Codec availability depends on installed encoders. File extension, video codec and audio codec must be compatible.
  • Quality meaning depends on codec/backend; a lower CRF-style value generally means a larger, higher-quality file.
  • This node can create additional exported files by design; current-result cache cleanup does not remove them.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
