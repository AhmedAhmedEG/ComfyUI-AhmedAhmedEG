MiniMax H3 Video Combine & Audio Muxer

Encodes an IMAGE frame batch and optional audio with advanced codec controls.

Output2 outputs

Use it when: Use it instead of the stock output pair when you need these export options.

In plain language

This turns a batch of individual pictures and optional sound into a video file. It provides more codec and quality controls than the basic saving path.

Your first use: Connect Master images to images and Master audio to audio. Match frame_rate to the Master’s fps, choose a filename prefix, and run. For your first video, keep the starter’s stock Create Video → Save Video path instead.

Connections

Master images → images; Master audio → audio
Master fps → frame_rate (convert the widget to an input when wiring)

Encode RGB frames and mux optional sound

Video Combine consumes a decoded IMAGE batch and optional AUDIO, writes a media file and returns an on-node preview plus frames/filename outputs. It performs no H3 sampling. Use it for advanced codec/container controls; ordinary Create Video → Save Video remains appropriate when those extra controls are unnecessary. The Master’s VHS_VIDEOINFO socket is metadata and must not be connected in place of images.

Master.images ─→ Video Combine.images
Master.audio ──→ Video Combine.audio
Master.fps ────→ Video Combine.frame_rate (convert widget to input)
filename output = encoded file path, not a native VIDEO object

Container, codec, backend and bit depth

container selects the packaging format; codec selects the video compression algorithm. MP4 is a container and H.264 a codec. MKV can package other combinations, while WebM requires VP9/AV1 in the FFmpeg path. Auto resolves to a supported default; it does not guarantee optimal size or browser compatibility. H.264/MP4/8-bit is a practical first compatibility test.

encoder_backend=pyav uses the vendored enhanced PyAV encoder and supports its animated WebP/AVIF modes where the installed libraries/codecs permit. ffmpeg streams raw frames to an FFmpeg subprocess and muxes a temporary audio WAV. Animated output is rejected by that path. FFmpeg must be installed or supplied by imageio-ffmpeg, and the selected codec must exist in its build. A missing encoder error is distinct from a bad H3 generation.

bit_depth chooses Auto/8-bit/10-bit output. The FFmpeg path uses RGB24 or RGB48 input conversion and YUV420 output formats. Ten-bit encoding can retain finer numeric gradations, but it does not add genuine detail to an eight-bit source or make an unsupported browser codec playable. quality is a compression quality/CRF-style number; lower usually means less compression and larger files. It is not an H3 sampler step count.

Time, audio and looping behavior

frame_rate tells the encoder how quickly to play the supplied frames. For 240 frames at 24 fps, the video is ten seconds; at 30 fps the same frames are eight seconds unless you resample beforehand. Use Output Processing when you want a deliberate change in frame count rather than an accidental retime.

audio_codec and audio_bitrate select sound compression; Auto follows the backend/container defaults, such as AAC for ordinary MP4 or Opus for WebM in the FFmpeg path. crop_to_audio permits shortening output to the available audio interval; it does not extend a short audio file to match the movie. pingpong creates a forward/backward visual sequence. The FFmpeg path appends reversed interior frames without duplicating both endpoints; do not assume the audio becomes a seamlessly reversed soundtrack.

Output files, returned frames and metadata

filename_prefix is relative to ComfyUI output or temporary storage and supports date placeholders such as %date:yyyy-MM-dd% and %date:hhmmss%. A matching existing filename gets a numbered suffix. Prefix traversal outside the intended directory is rejected. save_output=true writes persistent output; false selects temporary storage, which may be cleared later.

pass_frames=true returns the supplied/processed frame batch for a downstream stage; false returns a small first-frame result in the FFmpeg path. The encoded file still contains the complete supplied video. save_first_frame/save_last_frame optionally write endpoint PNGs. save_metadata records available workflow/prompt metadata; optional seed supports encoder metadata behavior and does not generate new sampling noise. log_level chooses diagnostic verbosity, not encoding quality.

Failures and a reliable baseline

Begin with a short generated clip, H.264, MP4, 8-bit and the correct FPS. If encoding fails, inspect the backend's error text for unsupported codec, invalid dimensions, malformed audio or unavailable binaries. AUDIO should be a supported waveform dictionary, and the FFmpeg path supports one audio batch. If the file exists but the browser refuses playback, inspect format compatibility rather than rerunning diffusion. Try the stock saver or another compatible codec for comparison.

Encoding can hold the IMAGE batch while iterating frames. It is not the per-shot streaming project exporter. For a long cached sequence, use Project / Shot Video Export to avoid loading a new complete decoded project batch solely for final assembly.

Implementation: FFmpeg encoder/path handling, PyAV enhanced encoder.

Execution summary

  • Encodes frames using PyAV by default, or the explicit FFmpeg backend.
  • Supports codec/container choices, bit depth, audio codec/bitrate, metadata, ping-pong, crop-to-audio and optional first/last stills.
  • Writes to output or temp according to save_output. The UI displays a video preview; frames are returned only when pass_frames is enabled.

How to use it

  1. Connect Master images and audio; set frame_rate to the Master fps.
  2. For a compatibility baseline, choose H.264, mp4, 8-bit and save_output true.
  3. Set filename_prefix and run the workflow.
  4. Use the returned filename or ComfyUI history to locate/download the video.

Limits and troubleshooting

  • filename is a path STRING, not a native VIDEO. Use stock Create Video / Save Video for the simplest starter.
  • Codec support depends on installed encoders. Animated output requires PyAV. pass_frames does not turn off encoding.
  • The browser fallback preview can be H.264 even when the saved file uses another codec.
