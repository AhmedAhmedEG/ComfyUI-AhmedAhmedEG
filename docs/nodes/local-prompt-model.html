Local Prompt / Vision Model

Configure a local Transformers or GGUF prompt-writing model.

Use it when: Use Prompt Forge without a remote drafting API.

1. What it does

Prompt-model weights are released after drafting instead of competing with H3 video generation.

2. Connect it

Local Prompt Model pipeline → Prompt Forge.generator

3. First use

  1. Select an installed supported model and its backend.
  2. Enable vision only for a supported model and provide its projection when required.
  3. Choose device and context size with available memory in mind.
  4. Keep unload_after_draft unless you intentionally reserve memory for faster later drafts.

7. Limits & troubleshooting

  • This is a language/vision model for prompt drafting, not FL2VA or REF2VA.
  • A large context or keep_loaded setting can consume substantial memory.
  • GGUF vision may need an exactly compatible projection file.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
