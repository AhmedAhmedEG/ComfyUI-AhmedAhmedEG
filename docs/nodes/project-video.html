Export Cached Project / Shots

Export current cached clips or stages as a complete video.

Use it when: Export a long project without retaining every decoded clip in one in-memory batch.

1. What it does

Available cached results are processed in timeline order without sampling new video.

2. Connect it

Master.project_state → Project Video.timeline
Optional Reference Pack → ref_pack
VIDEO → stock Save Video if desired

3. First use

  1. Connect the project state and choose the stream: final or an available current processing stage.
  2. Choose all clips or clip_ids. Use the clip selector and stable IDs for a subset.
  3. Choose output FPS and filename prefix; normally match generated timing.
  4. Run export and inspect the assembled video and optional individual shot files.

7. Limits & troubleshooting

  • Timeline project_id takes precedence over the fallback project_id widget.
  • Changing export FPS changes playback timing; it does not create interpolated motion.
  • Missing stage/cache files must be resolved; workflow JSON alone is not media.
  • Exported files are outside automatic replacement of superseded cache generations.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
