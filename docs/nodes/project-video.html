MiniMax H3 Project / Shot Video Export

Exports cached project shots one at a time and assembles a native VIDEO file.

Output2 outputs

Use it when: Use it for individual-shot export or rebuilding a saved sequence without resampling.

In plain language

This exports completed cached shots from a project and joins them into a video file. It reads saved shots one at a time, which can be useful for a long project.

Your first use: Choose the same project ID used by the Master and the export stream you want. Run after the relevant shots have finished. This node writes the file itself; a second Save Video is only needed if you deliberately want another copy.

Connections

Master project_state → timeline
Returned VIDEO → optional native VIDEO consumer

How it works

  • Reads the project ID from timeline first, otherwise from the project_id widget. Iterates shots in timeline order, optionally only selected shots.
  • final uses cached final frames; pre_refine uses the saved first-pass frames; original_source decodes source ranges. Locked shots use their sources.
  • Applies stored context/handoff trims, normalizes canvases, adjusts output FPS and audio, encodes shots, then concatenates their files with FFmpeg.
  • Returns a native VIDEO, individual shot-file JSON and an assembled UI preview.

How to use it

  1. Connect Master project_state to timeline, or supply a saved timeline JSON.
  2. Choose all/selected, stream, fps and filename_prefix.
  3. Enable export_individual_shots when you want permanent per-shot files as well.
  4. Run after the needed takes and source media are available.

Limits and troubleshooting

  • Requires FFmpeg for assembly and H.264 MP4 encoding support. It also writes an assembled output itself.
  • Missing final/pre-refine media can fall back to a source range when one exists; otherwise export fails.
  • Changing FPS repeats/drops frames; it does not add AI motion interpolation.
  • The assembled file is already written by this node; Save Video is only needed if you intentionally want another saved copy.
