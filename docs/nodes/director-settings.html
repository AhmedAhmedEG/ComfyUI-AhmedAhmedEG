MiniMax H3 Director Settings

Builds the canvas, sampling and execution configuration consumed by the Master.

Start here1 output

Use it when: Use this in every ordinary starter workflow.

In plain language

This is the control panel for how the video is generated. It sends settings to the Master; it does not make a video by itself. Width and height set the picture size. Steps set how many sampling iterations the AI takes. Seed is the starting random number.

Your first use: Connect config to the Master’s config input. Use the starter values for your first run. Change only one setting at a time. Keep seed fixed while comparing results so a new random starting point does not hide the effect of your change.

This node in the starter workflow. Read what every box does.

Connections

config → Master config

How it works

  • Returns one configuration dictionary. This node does not sample or decode media.
  • The Master uses this configuration as its baseline; active timeline resolution controls can override width and height.
  • When settings_optional is connected, this node overrides the matching canvas and sampling values while preserving other incoming settings.

How to use it

  1. Connect config to Master config.
  2. Choose Next shot, All shots or Conditioning only in Generation mode.
  3. Set resolution, sampler, steps and continuity. Prompt editing belongs to each shot; playback scope belongs to Smart Preview.

Limits and troubleshooting

  • A newly created node defaults to 1344 × 768, res_multistep and chained continuity. The starter uses 960 × 544, euler and Independent for the first test.
  • context_length choices are video-frame context lengths, unrelated to language-model context tokens.
  • Changing export playback FPS uses Output Processing; the Master generation frame_rate must stay at 24.
