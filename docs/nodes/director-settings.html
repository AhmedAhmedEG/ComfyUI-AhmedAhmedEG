Director Settings

Set the output canvas and initial sampling settings.

Use it when: Change generation dimensions and quality settings without filling the Master with global controls.

1. What it does

Quick, low-quality output suitable for detecting integration errors, not assessing final visual quality.

2. Connect it

Director Settings.config → Master.config

3. First use

  1. Choose Manual canvas for an explicit width and height, or Auto for megapixels plus aspect.
  2. Keep H3 generation at 24 fps. Use dimensions on the 32-pixel grid.
  3. Match steps and sampler to your chosen model/LoRA workflow.
  4. Keep decoded_output at latest for normal preview use; use Project Video to export the entire cached project.

4. Every option explained

width

Setting

The pixel dimensions used by this stage.

Use it when
Choose an explicit delivery or generation size when its canvas policy uses manual dimensions.
What changes
More pixels increase processing and memory; aspect mismatch may stretch, crop or pad according to the selected policy.
Keep in mind
H3 generation dimensions use a 32-pixel grid. A Refine target is ignored in same-resolution refine mode.

steps

Setting

Sampling iterations for this stage.

Use it when
Match the model workflow, or compare a small change while keeping seed and other settings fixed.
What changes
More iterations add computation; extra refinement steps are separate from initial generation.
Keep in mind
More steps do not guarantee improvement. Completed 10-step plus 15-step refinement is not an initial 25-step run.
Choices, defaults & connection details

Type: INT · Initial value: 25 · Required

Range: 1 to 200 · step 1

Strength of classifier-free guidance.

Use it when
Keep the H3 workflow baseline initially; change it only in a controlled comparison.
What changes
Changes the influence of guidance during diffusion and can change appearance or motion.
Keep in mind
Large values can introduce artifacts. The standard starter uses CFG 1.

Type: FLOAT · Initial value: 1.0 · Required

Range: 0.0 to 20.0 · step 0.1

decoded_output

Setting

Which clips the Master returns as a raw decoded IMAGE/AUDIO batch.

Use it when
Use latest for normal Smart Preview; use full only when downstream nodes need all raw frames.
What changes
latest reduces retained decoded output while all current clips remain in the server cache.
Keep in mind
This is separate from Smart Preview’s Latest clip / Full video choice.
Choices, defaults & connection details

Type: COMBO · Initial value: latest · Optional

full
Return a full assembled raw frame/audio batch. Uses more output storage/retention.
latest
Return only the last output clip as raw frames/audio; keep all current cache results for preview/export.

7. Limits & troubleshooting

  • Generation output size and reference-media size are separate controls. Reference video megapixels belong in Reference Pack.
  • Changing dimensions, schedule, LoRAs, attention or continuity can change output despite the same prompt and seed.
  • Higher steps and more pixels cost time; neither guarantees better content.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
