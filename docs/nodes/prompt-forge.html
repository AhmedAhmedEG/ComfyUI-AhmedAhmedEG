Prompt Forge Draft

Draft editable clip prompts using a configured language/vision model.

Use it when: Turn a brief into proposed shots while keeping generation and applying edits separate.

1. What it does

The result is an editable proposal, not three generated videos.

2. Connect it

Timeline data → Prompt Forge.timeline
Local Prompt Model → generator (local backend)
draft → Apply Prompt Draft

3. First use

  1. Choose local, Ollama or a compatible API backend and configure the actual provider.
  2. Describe the shots and set shot_count, creativity and detail.
  3. Run drafting and review the returned prompts or editor proposal.
  4. Apply deliberately through Apply Prompt Draft or the reviewed authoring interface.

7. Limits & troubleshooting

  • External backends receive the prompt/context you submit; select a provider you intend to use.
  • Changing source context invalidates stale drafts instead of silently applying them.
  • A draft cannot guarantee a video model will reproduce the described action.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
