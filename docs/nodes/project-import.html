Project Import

Review and convert supported project data into this pack’s timeline.

Use it when: Bring a supported foreign project or this pack’s exported project into a compatible graph.

1. What it does

The converter reports what it could map. It does not guarantee another project’s algorithms become identical.

2. Connect it

project JSON / source → Project Import
converted timeline → compatible timeline consumer

3. First use

  1. Choose the supported source format or automatic detection.
  2. Review conversion notes and missing assets before applying.
  3. Enable model restoration only when you intentionally want recorded compatible model selections.
  4. Reconnect files and model loaders required by the converted project.

4. Every option explained

restore_models

Setting

Load explicitly named installed diffusion checkpoints into the imported model pack.

Use it when
Enable only when you want the import to load its recorded installed models.
What changes
Loads model weights and returns model bindings; this can consume RAM and VRAM when used.
Keep in mind
Missing or ambiguous bindings fail. It does not download weights or prove algorithmic parity.
Choices, defaults & connection details

Type: BOOLEAN · Initial value: false · Optional

7. Limits & troubleshooting

  • A project file can describe files that are absent on this server.
  • Restored cache results require compatible cache data, not just a matching project display name.
  • Unknown source features should be reviewed rather than assumed equivalent.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
