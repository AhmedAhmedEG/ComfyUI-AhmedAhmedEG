In plain language

Review authoring conversion before use.

Your first use: This converter reads supported authoring metadata from current timelines, DaSiWa reference packs, AIMixer timeline lists and Tritant Extender projects. The panel accepts JSON or a project ZIP/EXT archive, then Convert And Review displays a converted timeline and warnings. Apply Converted Timeline updates a chosen local Master only after review. Alternatively, connect the typed timeline output to Master.timeline to keep the converter as its authoring owner. Do not use both authoring paths for the same Master.

Connections

timeline → Master.timeline, or reviewed panel apply to a local Master
config → Master.config; model_pack → Master.model_pack; refmods → Reference Pack.refmods

Reviewed project conversion

Choose JSON, ZIP or EXT, then Convert And Review. Inspect the conversion report before Apply Converted Timeline, or connect the typed timeline to Master. Use one authoring path. Archives stream to disk and embedded media is extracted beneath a content-namespaced input directory after path validation.

Recognized sampling/canvas values are returned on config. Explicit installed checkpoint aliases can be restored with Restore Models and returned on model_pack; missing or ambiguous names fail rather than substituting weights. RefMod selections use the existing library output and enter Reference Pack. These optional outputs append to the original timeline/report ports.

Restore Compatible Takes reads known Tritant raw H3 audiovisual cache descriptors and restores one segment at a time. Every descriptor is checked before take commits. Compatible approved takes retain approval and Master decodes them with connected H3 VAEs without sampling. Other authoring conversion clears approval. Decoded foreign previews are not evidence of a compatible latent.

The report lists missing files and unsupported fields. Opaque runtime objects and unsupported binary serializers cannot be reconstructed without their source data. Available saved prompt history and explicit loader filenames are recovered for review. Preserve your original archive. Normal Save/Open remains the owner of current projects.

Workflow and transfer compatibility

Saved workflow JSON with one recognized Director/Extender timeline can provide authoring metadata, cast labels/boxes, saved DaSiWa Forge history and UNETLoader filenames. The importer does not execute foreign nodes or guess unnamed numeric widget positions. Several matching timelines produce an explicit ambiguity error. Recovered checkpoints become named model-pack aliases; compatible installed weights still need Restore Models and the intended graph connections.

File transfers report upload and download bytes in the browser. The server separately reports extraction, take restoration and media packing. Each percentage names its phase; upload 100% does not claim conversion is finished. Errors retain their messages and transfer listeners are removed on completion/cancellation.

Execution summary

  • Converts recognized authoring fields and lists missing files and unsupported source fields for review.
  • The panel streams archives to the server. Restore Compatible Takes imports validated native H3 raw audiovisual cache segments from Tritant archives without foreign pickle execution.
  • Recognized sampling settings are returned on config; explicit installed checkpoint bindings on model_pack require Restore Models. RefMod selections use the existing library contract.

Limits and troubleshooting

  • Archive paths are checked before any media extraction. Absolute paths, parent traversal and unsupported archive structure are rejected. Supported embedded media is copied into a content-namespaced directory beneath the server input folder; it is not copied into the model folders. Missing media is listed in the report. JSON conversion alone cannot transfer files from another machine. AIMixer conversion requires an explicit clip, segment or group list, and unsupported rich fields require manual review. This is a metadata migration tool, not binary compatibility with every historical project serializer. Preserve your original archive and inspect prompts, media assignments and durations before running a model.
  • Authoring conversion alone clears approval. Only restored compatible cached takes preserve their source approval. Unnamed graph checkpoint objects, arbitrary historical formats and foreign Forge history cannot be reconstructed.
  • Saved foreign workflow JSON can recover one recognized Director/Extender timeline, explicit UNET loader filenames, cast/reference metadata and available DaSiWa prompt history. Ambiguous multiple timelines fail instead of choosing one. Numeric widget positions and arbitrary procedural graph patches are not guessed. Upload, server extraction/cache restoration, packing and download phases report scoped progress.
