MiniMax H3 Playback / Watermark / Loop

Changes decoded playback timing, adds a watermark and optionally creates a loop.

Output3 outputs

Use it when: Use it between the Master and a video encoder.

In plain language

This changes finished frames and sound after generation: playback speed, a logo or text watermark, or a loop transition. It does not change the prompt or rerun the video AI.

Your first use: Connect Master images and audio, choose one change first, then send the processed outputs to Create Video → Save Video. Check the resulting duration and sound when changing speed. Overlapping the ends for a loop shortens the result.

Connections

Master images / audio / fps → images / audio / source_fps
IMAGE / AUDIO / FLOAT → Create Video images / audio / fps

Decoded media operations after generation

Connect decoded images and optional audio after the Master or a cached take. This node applies playback conversion, then watermark, then optional loop construction, and returns IMAGE, AUDIO and the output FPS. It does not alter latent sampling, references, model conditioning or cached approval on its own. Wire its returned FPS into your encoder rather than leaving the saver at an unrelated value.

Resample versus retime

source_fps describes the input's time basis; playback_fps the desired output time basis. playback_policy=resample changes frame selection/count to approximately preserve duration. This uses frame selection/duplication, not optical-flow creation of new motion. retime plays the original frame sequence at a different rate and adapts supported audio timing, changing duration. Audio retiming changes pitch as well as speed; this is not pitch-preserving time stretching.

For 240 input frames at 24 fps: resample to 30 fps produces approximately 300 frames lasting ten seconds; retime to 30 fps keeps the visual frame sequence and lasts eight seconds. The first changes sampling density, the second changes speed. Neither changes the original H3 latent's native frame grid.

Text, logo, opacity and position

watermark_text adds supplied text; optional logo supplies an IMAGE overlay. opacity sets overlay strength from zero to one. corner chooses one of the four named corners. A blank text field and absent logo leave no visible watermark. Zero opacity can make an otherwise configured overlay invisible.

Watermark processing edits RGB frames; it is not a metadata copyright tag and does not protect model identities. A logo batch should represent the intended overlay rather than an unrelated movie. Inspect placement against the actual output dimensions before exporting a whole project.

Joining the end back to the beginning

loop_overlap_frames=0 disables the loop operation. A positive overlap blends the boundary region to improve the visual/audio join. It consumes an overlap interval rather than generating new context. At 24 fps, 12 overlap frames represent half a second; a very large overlap can consume a substantial fraction of a short shot.

A crossfade can soften a brightness jump but cannot make incompatible subject positions or motions physically continuous. Generate an action designed to loop, then use modest overlap as finishing work. Compare the resulting frame count and duration before saving.

Master.images/audio ─→ Output Processing
source_fps=24, playback_fps=30, policy=resample
Output Processing IMAGE/AUDIO/FLOAT ─→ encoder images/audio/frame_rate

Changing only the saver FPS skips this node's resample policy and can cause an accidental speed change or audio mismatch. Missing audio input is valid for silent visual processing; it does not request H3 to synthesize new sound.

Implementation: node order, playback/watermark/loop functions.

Execution summary

  • resample repeats/drops frames to preserve duration at playback_fps. retime changes duration and audio pitch.
  • Applies a logo or text watermark; a connected logo takes precedence over text.
  • A positive loop overlap crossfades the end into the beginning and shortens the sequence by that overlap. Returns processed frames, audio and playback FPS.

How to use it

  1. Connect Master images, audio and fps as source_fps.
  2. Choose playback_fps and policy; leave rates equal for no timing change.
  3. Set watermark text or connect a logo, then choose corner and opacity.
  4. Use loop_overlap_frames only when a loop is needed; connect all three processed outputs to the encoder.

Limits and troubleshooting

  • Resampling is not optical-flow or AI frame interpolation. Retime changes pitch.
  • Loop overlap must be less than half the frame count. For example, 124 frames with a 12-frame overlap produces 112 frames.
