Playback / Watermark / Loop

Adjust decoded playback, add a watermark or create a loop.

Use it when: Apply final presentation changes after generation rather than changing model conditioning.

1. What it does

The watermark is burned into decoded output; it does not change sampled latents.

2. Connect it

Decoded frames → images; matching audio → audio
Processed frames/audio/fps → encoder

3. First use

  1. Enter the actual source FPS and intended playback FPS.
  2. Choose resample to preserve duration by dropping/repeating pictures, or retime to change playback speed and audio pitch.
  3. Set watermark text or a logo, opacity and corner if wanted.
  4. Use loop overlap only when the clip’s beginning and ending content can blend naturally.

7. Limits & troubleshooting

  • resample changes picture count without creating learned motion; retime changes speed and audio pitch. Use Frame Interpolation for intermediate picture synthesis.
  • A connected logo takes precedence over text.
  • Overlaps and playback changes can alter duration; connect returned FPS and audio to your encoder.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
