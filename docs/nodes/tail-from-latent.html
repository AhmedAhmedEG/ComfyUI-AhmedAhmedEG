Tail From Latent

Decode the end of a sampled H3 latent into reference video, paired sound and a final frame.

Use it when: Bridge a compatible sampled latent into a graph that needs ending frames and audio.

1. What it does

The ending frames and audio are decoded without regenerating the original clip. This node does not return an MMX_CONTINUATION object.

2. Connect it

Sampled H3 LATENT → samples
Video/audio VAEs → matching inputs
ref_video + ref_video_audio → Reference Pack video and paired-audio inputs
last_frame → a compatible keyframe/reference input

3. First use

  1. Supply a compatible audiovisual latent and its VAEs.
  2. Choose the tail duration and whether to align it to H3’s temporal grid.
  3. Inspect the returned tail before using it to continue a clip.

7. Limits & troubleshooting

  • A preview MP4 cannot substitute for the sampled latent.
  • Matching VAE families and valid audiovisual shapes are required; this does not resume denoising steps.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
