MiniMax H3 Tail From Latent

Decodes a sampled H3 joint audiovisual latent and returns its ending frames and audio.

Advanced graph tools5 outputs

Use it when: Use it for manual sampler graphs that need a continuation tail.

In plain language

This takes an already sampled compressed video/audio result, decodes it, and returns the ending pictures and sound. Those ending frames can guide a continuation.

Your first use: This is an advanced graph tool. Connect a completed H3 latent plus its video/audio decoders. Use the returned tail when building a continuation workflow. For ordinary consecutive shots, use the Master’s chained continuity controls instead.

Connections

Sampled H3 LATENT → samples
Video VAE → vae; Audio VAE → audio_vae

How it works

  • Decodes the full latent with the video/audio VAEs, then selects the final tail_seconds of media.
  • When alignment is enabled, selects a nearby valid H3 frame-grid length within the available frames.
  • Returns the tail frame batch, matching tail audio, last frame, frame count and duration.

How to use it

  1. Connect a sampled H3 LATENT, the video VAE and the audio VAE.
  2. Start with tail_seconds 0.5 and grid alignment enabled.
  3. Use ref_video and ref_video_audio as manual continuation references, or last_frame as an endpoint image.

Settings and controls

Initial values come from the node’s declared UI schema. The starter can use different values. Required settings have widgets; they do not all require cables. Runtime model/sampler choices depend on your installation.

Limits and troubleshooting

  • This performs decoding again; use Load Take Checkpoint when you already have a durable completed take.
  • video_vae is an optional alias that takes precedence over vae.
