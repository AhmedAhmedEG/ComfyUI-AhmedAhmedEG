MiniMax H3 Master Node

Authors and generates a timeline of MiniMax H3 shots with video and audio.

Start here10 outputs

Use it when: Use this as the centre of a normal workflow.

In plain language

This is where you direct the video. A shot is one short clip. You give each shot a written description, a length and, optionally, pictures or other media to follow. The Master runs the AI and joins the completed shots.

Your first use: Write a two-second text shot in the Master, select Next shot in Settings, and click Run. Watch the result in the separate Smart Preview node. Add images, video or audio through Reference Pack when needed.

This node in the starter workflow. Read what every box does.

How it works

  • Reads the timeline, settings and each shot’s media assignments. Resolves a model family and prompt for each shot.
  • For text, opening/closing-frame and still-image modes, uses FL2VA. REF2VA, V2V and RV2V use REF2VA. Connected family models are loaded lazily.
  • Generates a new take or reuses a matching saved take. Applies enabled SelfLift, Refine and FaceRefine stages, then assembles the requested output.
  • Clip-by-clip stops after one newly generated shot. Full-batch works through the sequence. Conditioning Guide Output emits the last shot’s conditioning and latent for an external sampler.
  • The separate Smart Preview node reads completed cache takes. Its Latest clip / Full video switch controls what your browser downloads.

How to use it

  1. Select the installed files and configure Generation mode in Settings.
  2. Supply media only through connected Reference Packs. Assign existing named items to shots.
  3. Edit prompts with the per-shot Raw / Structured switch and click Run. Watch the separate Smart Preview.

Shot editor

Drag a shot body to reorder it, drag its right edge to change duration, or click × / Delete Shot to remove it. References move with the shot. Dragging outside cancels safely.

Reference Pack is the sole source of new reference media. Connect image, video-frame or audio loaders to the pool; optional names identify them in the Master. Only existing connections appear. Assign a pool item to a shot to reveal its prompt token. Click an image thumbnail for a full-size preview. Empty media tracks stay hidden.

Raw / Structured is a per-shot editing choice. Generation mode lives in Director Settings. Preview scope and autoplay live in Smart Preview. H3 generation is 24 fps, with dimensions in multiples of 32 and durations rounded to the 5 + 17k grid.

Advanced source edits

For V2V / RV2V, select a video provided by the pool. File-backed inputs offer source-range splitting and merging. Existing saved projects retain legacy source compatibility; new uploads are handled upstream, not inside the Master.

Project files

Workflow JSON stores the graph and controls. Generated takes stay in the server cache. Export uses the consolidated workflow; Save preview downloads the smaller preview copy.

Limits and troubleshooting

  • Generation is fixed at 24 fps. Canvas dimensions must be multiples of 32. Generated durations round to the 5 + 17k frame grid.
  • video is VHS_VIDEOINFO metadata, not a native VIDEO object. Use Create Video to package images and audio.
  • prompt_text accepts one prompt per nonblank line. External group inputs replace timeline shots; prompt_text overrides existing shot prompts in line order; shots beyond the supplied lines keep their prompts. With no shots, lines construct new shots.
  • timeline_data and builder_state are editor-managed JSON. Normal users edit the visible UI rather than those values.
  • Latest preview fits within 960 × 540; final exports use the configured generated frames. A cache contains completed takes, not an unfinished sampler step.
  • Conditioning Guide Output returns placeholder images/audio; use its conditioning and latent in an external sampling/decoding graph.
