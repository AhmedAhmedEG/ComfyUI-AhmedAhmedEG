Master Node

Build and generate a sequence of clips from one timeline.

Use it when: Start here for prompts, per-clip references, continuity, approval and clip LoRAs.

1. What it does

Only assigned references become that clip’s reference inputs; unrelated pool entries do not all go to the model.

2. Connect it

Director Settings.config → Master.config
Reference Pack.ref_pack → Master.ref_pack
FL2VA model → Master.fl2va_model
REF2VA model → Master.ref2va_model
Text encoder → Master.clip; VAEs → matching VAE inputs
Master.project_state → Smart Preview.project_state

3. First use

  1. Load the starter and select installed model, text encoder and VAE files.
  2. Add a clip and choose its type. Assign only the references that clip needs.
  3. Write the clip prompt. Start with one short clip and optional stages disconnected.
  4. Choose Next clip or All clips, then run. Review the result and approve only clips you want reused.

5. Practical examples

Use case 01

Keep a character consistent

Set it up
Choose REF2V and select the character pictures from the connected pool. Mention the generated Picture tokens in the prompt.
Expect
Only assigned references become that clip’s reference inputs; unrelated pool entries do not all go to the model.
Use case 02

Continue an action

Set it up
On clip 2 choose Motion Context, set video and audio context independently, and choose New footage duration.
Expect
The previous completed result supplies context. Context is removed from delivered new frames.
Use case 03

Replace a middle clip

Set it up
Unapprove the clip. Continuity-dependent later approvals are invalidated while their cached results remain until replacement.
Expect
A run regenerates the eligible clips and replaces their current results. Approved independent results remain reusable.

7. Limits & troubleshooting

  • FL2VA serves text/keyframe tasks; REF2VA serves reference/video editing tasks. Keeping both connected does not force one model for every clip.
  • Approval controls generation reuse. It does not decide which completed idle results Smart Preview may display.
  • Saved results contain completed latents, not persistent paused sampler state. Ten completed steps plus fifteen refinement steps is not twenty-five initial steps.
  • The yellow outline is selection. Saved-result indicators, approval and the active generation animation have different meanings.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
