MiniMax H3 Master Node

Authors and generates a timeline of MiniMax H3 shots with video and audio.

Start here10 outputs

Use it when: Use this as the centre of a normal workflow.

How it works

  • Reads the timeline, settings and each shot’s media assignments. Resolves a model family and prompt for each shot.
  • For text, opening/closing-frame and still-image modes, uses FL2VA. REF2VA, V2V and RV2V use REF2VA. Connected family models are loaded lazily.
  • Generates a new take or reuses a matching saved take. Applies enabled SelfLift, Refine and FaceRefine stages, then assembles the requested output.
  • Clip-by-clip stops after one newly generated shot. Full-batch works through the sequence. Conditioning Guide Output emits the last shot’s conditioning and latent for an external sampler.
  • The Preview tab requests separate latest-clip or complete-sequence preview files from completed caches. It does not change the Output selection.

How to use it

  1. Load the starter and select both diffusion models, CLIP type minimax, and the video/audio VAEs.
  2. Edit a shot’s mode, duration, prompt, audio policy and references in the Shots tab.
  3. Run the workflow and inspect Preview → Latest clip. Validate a take you accept.
  4. Add a shot and choose independent or chained continuity. Set Output → Full Video for a complete downstream export.

Shot editor

Move: drag a shot’s body left or right. The insertion marker shows its new position; image, video and audio assignments move with it. Shots stay joined without gaps. Move earlier / Move later buttons offer the same operation.

Resize: drag the shot’s right edge to change duration. Delete: click × on the shot or Delete Shot in its inspector, then confirm. The last shot can be deleted; use + Add Shot to start again. A locked source stays in place. Reordering or deleting clears approval on affected later shots so chained output is regenerated.

Use Director Settings for size, steps, seed, execution and continuity. Use the Master for shots, prompts, references and review.

  • Keep a fixed seed while comparing a setting. Increment, decrement or randomize requests the next variation.
  • Only selected shots are generated when Generate selected shots is enabled. Unselected source ranges can pass through unchanged.
  • Validate a completed take to approve it. Reuse also requires matching inputs and files; changing a chained shot can invalidate its successors.
  • Generation uses a 24 fps frame grid: 5, 22, 39, 56, 73… frames. Width and height must be multiples of 32.

All-in-One Generation is the usual execution mode. Clip-by-clip stops after one new shot; full-batch processes the sequence. Manual resolution uses your dimensions, Auto uses aspect and megapixels, and Original snaps the source dimensions to the grid. Active working-resolution overrides take precedence.

Prompts and shot LoRAs

  • Example: A cyclist turns onto a wet street. Low tracking camera. Evening shop lights. Tires hiss on pavement.
  • Use raw text or structured editing; shared text supplies recurring instructions.
  • Mention selected media with the editor’s reference tokens. Check resolved_prompt to see what H3 receives.
  • Attach up to 8 LoRAs per shot.
  • Start with a moderate strength; compare with the same seed.
  • LoRAs modify the model; reference assets and RefMods supply media.

References and timed guides

Add & prepare reference media

  • Trim video/audio by start/end seconds; choose video, audio or both. The waveform shows decoded audio peaks.
  • Crop images/video using the rectangle or numeric fields. Scale with Off / Auto / Target / Fit / Fill; crop or pad to the required grid.
  • Set role and description. Subject/place/style/keyframe/pose are descriptive labels; pose is not a skeleton ControlNet.

Use RefMods & bundles

  • Use <RefMod 1> or <RefMod 1:memberName> to mention a bundle/member.
  • Expanded members count toward the normal reference limits.
  • RefMods organize reference assets; this node does not train or create a new RefMod model.

Place a guide at a time

  • Enter the guide time in seconds inside the visible shot.
  • The native AddGuide path offsets the anchor for a continuity prefix.
  • Check the reference and timestamp when an anchor lands at the wrong point.

Limits: 9 images, 3 videos, 3 audios, 12 combined; each reference video and their total duration must be ≤15 seconds. Native H3 may impose additional combination constraints. Crops retain the original asset; picking a source frame uses the original player time.

This is a timestamped native guide, not an additional guide-strength control.

Source-video editing

  • Use V2V/RV2V and describe the desired edit. The source becomes reference Video 1.
  • Split at the playhead, split equally or use optional scene detection. Merge only contiguous ranges from the same file.
  • Leave other ranges unselected for source passthrough; generated ranges are trimmed to the source length.

There is no generic source-latent strength slider. Automatic continuity prefixes are disabled for source edits. Scene detection needs scenedetect[opencv]. To extend a video, use locked source Clip 0, then add generated shots. Source ranges keep original-time coordinates.

Project files and recovery

  • Workflow JSON: graph and node settings. Lightweight project JSON: timeline/settings with asset and cache hints.
  • Portable .mmxproj: includes reference/source bytes; excludes models and heavy generated takes.
  • Append remaps incoming IDs; overwrite replaces authoring. New Project / Reset Timeline / Clear Cache have different scopes.

Clear Cache removes generated takes while retaining uploaded assets. Appended shared references become local to imported shots. Back up generated-take storage separately when moving servers.

Limits and troubleshooting

  • Generation is fixed at 24 fps. Canvas dimensions must be multiples of 32. Generated durations round to the 5 + 17k frame grid.
  • video is VHS_VIDEOINFO metadata, not a native VIDEO object. Use Create Video to package images and audio.
  • prompt_text accepts one prompt per nonblank line. External group inputs replace timeline shots; prompt_text overrides existing shot prompts in line order; shots beyond the supplied lines keep their prompts. With no shots, lines construct new shots.
  • timeline_data and builder_state are editor-managed JSON. Normal users edit the visible UI rather than those values.
  • Latest preview fits within 960 × 540; final exports use the configured generated frames. A cache contains completed takes, not an unfinished sampler step.
  • Conditioning Guide Output returns placeholder images/audio; use its conditioning and latent in an external sampling/decoding graph.
