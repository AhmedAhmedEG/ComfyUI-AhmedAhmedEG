MiniMax H3 Director SelfLift

Configures a low-resolution sampling stage followed by a full-resolution finish.

Enhancements1 output

Use it when: Use it to try reducing the cost of high-resolution sampling.

In plain language

This optional setting makes the AI begin with a smaller picture and finish at the chosen picture size. A smaller first stage can reduce the work done early in generation. It can also change fine details, so compare it with ordinary generation.

Your first use: Connect selflift to the Master’s selflift input. Generate a baseline without it first. Then enable this node and compare the same prompt and seed. This node supplies instructions, not finished frames.

Connections

selflift → Master selflift
Optional compatible MODEL → model_hires

Progressive sampling instead of generating a small finished movie

SelfLift splits a single H3 sampling schedule into a low-resolution beginning and a full-resolution finish. Early steps establish the scene on a smaller spatial latent. At the transition, the video latent and its spatial conditioning are lifted to the final canvas, then the remaining steps finish it. This is different from decoding a small movie and resizing its pixels afterwards. The temporal length and audiovisual task remain part of the same generation.

Connect selflift → Master.selflift. This node itself returns a configuration pack; it performs no model sampling. Disconnect it for an ordinary full-resolution baseline. It can be combined with later Refine, but adding both increases the number of stages and makes it harder to identify which one changed an artifact.

Choosing the split and the low-resolution canvas

lowres_scale is a linear spatial scale, not a percentage of steps. At 0.5, both axes are approximately halved, so the low-resolution stage has roughly one quarter as many spatial cells. Dimensions are still constrained by H3 alignment. At 1.0, there is no meaningful spatial reduction. A smaller scale reduces early spatial work but can discard composition or fine features that the high-resolution finish must recover.

split_mode=highres_steps reserves the final highres_steps iterations for the full canvas. For 25 total steps and 4 high-resolution steps, the conceptual split is 21 low + 4 high. split_mode=transition_step specifies the low-stage transition using transition_step. The implementation clamps the split to the actual schedule; it cannot manufacture more sampler intervals than exist. Choose only one split rule—the unused field is not a second additional phase.

sampler_mode=euler selects the progressive Euler path. follow_director uses the Director-selected sampler path supported by the adapter. model_hires optionally supplies the compatible H3 model used for the high-resolution stage. Its conditioning and latent channels must remain compatible; a different MODEL architecture is not a valid high-resolution decoder.

How the spatial lift is constructed

latent_upscale_model selects an installed H3 latent upscaler, where available. It processes compressed video representations rather than RGB images; an ordinary UPSCALE_MODEL belongs to Pixel Upscale instead. latent_upsample chooses bilinear or nearest interpolation for the applicable fallback/lift path. Bilinear smooths between cells; nearest preserves discrete cell values and can look blockier.

rho controls an optional blend with a pixel-anchored latent at the lift. The progressive code can decode/resize/re-encode its anchor and mix it with the lifted result. At zero, that optional anchor blend is disabled. w_min/w_max bound its spatial weighting; the pack normalizes the ordering if the lower/upper values are reversed. These are not CFG, a seed or an audio mix. Leave rho at zero for the first comparison, then change it while keeping the split and seed fixed.

native_low_carry preserves applicable low-resolution carry data across connected segments so each new low-stage sample can use low-stage context. It matters in a multi-shot continuity pipeline, not when generating one independent shot. It is not a request to reuse a completed take without fingerprint checking.

Tiling, chunking and a controlled comparison

enable_tiling requests spatial sampling tiles; tile_count controls their division and tile_overlap their overlapping pixel coverage. More tiles can reduce peak spatial work but add repeated overlap work and potential seams. Temporal latent chunking, enabled by enable_latent_chunking, addresses the upscaling operation's temporal working set rather than dividing the authored shot into new timeline clips.

  1. Generate one independent 960×544 shot without SelfLift and retain its seed/prompt.
  2. Connect SelfLift, choose scale 0.5, split by highres_steps, and reserve 4 high-resolution steps from the 25-step schedule.
  3. Keep rho zero, the same models and the same references. Run a new take and compare composition, faces and motion.
  4. Only then try learned lifting, another split or memory controls. Revalidate the take you prefer.

This stage changes generation inputs and cache fingerprints. No fixed speedup or equal-quality guarantee follows from a lowres_scale value; short Turbo schedules in particular leave less room for an effective low/high split.

Implementation: node pack, normalization and split, progressive sampling, lift/anchor blend.

Execution summary

  • Returns a settings pack; the Master applies it during sampling.
  • lowres_scale changes the initial spatial size. split_mode chooses a fixed number of final high-resolution steps or a transition step.
  • The visual latent is enlarged between stages. Optional native low-resolution carry supports compatible chained shots; rho enables a pixel-anchor mixing path.

How to use it

  1. Connect selflift to the Master selflift socket.
  2. Start with lowres_scale 0.5 and highres_steps 4.
  3. Use follow_director if you want the main sampler selection; euler selects the SelfLift sampler path.
  4. Compare a fixed-seed baseline before trying learned weights, tiling, chunks or anchor mixing.

Additional usage

The weight dropdown has no explicit “interpolate” entry: when no weights are installed, its unset placeholder falls back to interpolation. native_low_carry reuses compatible low-resolution context only for chained shots. rho=0 disables the optional pixel-anchor mix; w_min/w_max bound its weighting.

Limits and troubleshooting

  • Missing learned upscaler weights fall back to interpolation; this node has no explicit interpolate item in its weight dropdown.
  • model_hires affects only the high-resolution stage and must be compatible with the shot family.
