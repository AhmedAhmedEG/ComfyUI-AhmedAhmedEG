Director SelfLift

Do early generation steps on a smaller canvas, lift the latent, then finish at target size.

Use it when: Experiment with generation cost after you have a working full-resolution baseline.

1. What it does

This is one staged initial generation, not a separate Refine pass.

2. Connect it

SelfLift.selflift → Master.selflift
Learned H3 latent upscaler must be installed and selected

3. First use

  1. Keep the same prompt, references, seed and target canvas for a baseline with SelfLift disconnected.
  2. Connect SelfLift and select a compatible learned H3 latent upscaler.
  3. Choose lowres_scale and the split: final highres_steps or an explicit transition_step.
  4. Review fine details and motion against the baseline before adopting it for a sequence.

7. Limits & troubleshooting

  • SelfLift can alter faces, hands, framing and motion. It is an optional tradeoff, not a guaranteed speed or quality improvement.
  • Euler-state support and sampler compatibility are checked. Follow Director does not make every sampler valid.
  • rho adds a pixel-anchor path with extra decode/encode work.
  • SelfLift runs before Refine. Reference Pack megapixels resize conditioning media, not this generation canvas.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
