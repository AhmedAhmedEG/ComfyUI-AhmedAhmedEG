MiniMax H3 Director Group (Reference to Video)

Packs one REF2VA shot with graph-supplied images, video frames and audio.

Advanced graph tools1 output

Use it when: Use it for a reference-driven graph-authored shot.

In plain language

This packages one reference-guided shot outside the Master editor. Reference media show the AI what a subject, scene, style or motion should resemble. A reference is guidance, not a guarantee of an identical copy.

Your first use: Enter a prompt, connect your reference media and connect the group to the Master’s r2v_groups input. This uses the REF2VA diffusion model. For a first manual reference shot, uploading and assigning media inside the Master is easier.

Connections

IMAGE → ref_image_1; optional frame batch → ref_video_1; AUDIO → ref_audio_1
group → Master r2v_groups

An explicit REF2VA shot from cables

This advanced packer creates one reference-guided shot without using the Master’s pool-selection editor. Its output is MMX_DIR_GROUP with family r2v and kind r2v; the Master normalizes that task to REF2VA. Connect it to Master.r2v_groups or a Groups Combine node. You still need the REF2VA model, MiniMax CLIP and both VAEs at the Master.

prompt describes the action/reference role; duration_sec is requested visible length. ref_image_size chooses match, 1024, 1280, 1536 or max for the group's reference-image preparation policy. It is not the generated canvas; Director Settings still determines generation dimensions. Larger reference preparation can retain detail while increasing conditioning cost.

Image, video and audio slots

ref_image_1…ref_image_9 accept IMAGE references. Optional ref_images accepts the legacy REF_PACK dictionary of keyed image tensors; direct occupied image sockets overwrite matching dictionary keys. This legacy dictionary type is not MMX_REF_PACK from the ordinary Reference Pack (Pool). A cable type mismatch is therefore meaningful rather than a missing automatic conversion.

ref_video_1 accepts a decoded frame batch, and ref_audio_1 an AUDIO object. The group stores separate ref_images, ref_videos and ref_audios dictionaries. A video filename alone is not valid frame data. Native validation and duration/reference limits still apply in the Master. Audio references without usable visual references are not a supported way to request an audio-only generation pipeline.

Load Image (character) ─→ Group.ref_image_1
Video loader frames ───→ Group.ref_video_1
Audio loader AUDIO ────→ Group.ref_audio_1
Group.group ───────────→ Master.r2v_groups
REF2VA MODEL ──────────→ Master.ref2va_model

Write the prompt with tokens matching the supplied group's ordered references. Start with one image and one clear role before adding motion/audio examples. This packer does not discover extra references from a token string or a model name. The large source pool used by ordinary editor shots and this group's limited explicit inputs serve different authoring workflows.

Expected failures and debugging

If the task reports no visual references, inspect actual connected media, not whether the prompt mentions Picture 1. If a custom video loader outputs VIDEO rather than IMAGE, decode it to frames first. If a generated result ignores the desired reference role, simplify the prompt and inspect the resolved task conditioning. A correct graph connection demonstrates data flow, not a guarantee that a model will reproduce a pose or identity exactly.

Implementation: reference group dictionary, reference limits.

Execution summary

  • Collects connected image slots, a video-frame batch and audio into one reference-family group.
  • Prompt, duration and reference image-size policy are preserved for Master execution.

How to use it

  1. Set a prompt and duration_sec.
  2. Connect a visual reference; optional audio references need a visual reference alongside them.
  3. Connect group to Master r2v_groups, directly or through Groups Combine.

Limits and troubleshooting

  • ref_images uses the separate REF_PACK type. It is not compatible with this pack’s MMX_REF_PACK output; use individual image inputs for normal graph wiring.
  • Native REF2VA reference-count and duration constraints still apply.
  • The Master converts external groups into independent shots with continuity disabled.
