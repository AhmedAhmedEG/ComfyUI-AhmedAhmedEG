Director Group (Reference to Video)

Describe one reference-guided clip as graph data.

Use it when: Build reusable graph templates with explicit image, video and audio reference inputs.

1. What it does

Only that group’s connected references are assigned to its generated clip.

2. Connect it

Reference IMAGE / video frame batch / AUDIO → matching group inputs
group → Timeline Builder → Master.timeline

3. First use

  1. Write prompt and duration.
  2. Connect only the references for this clip, using numbered images or the image batch input.
  3. Choose ref_image_size when you need this graph group’s native reference-image policy.
  4. Build the timeline and connect it to Master.

Requested clip duration in seconds.

ref_image_size

Setting

The native reference-image size policy for this graph group.

Use it when
Use match to follow its intended native policy or choose a supported specific option.

Changes preparation for these group image references.
Keep in mind
Reference Pack scaling is the owner of edits to pool assets; this graph group is an alternative authoring path.

7. Limits & troubleshooting

  • A group packs instructions; Master still needs models, VAEs and text encoder.
  • Native reference capacity and media constraints still apply. Graph authoring is not an escape from model limits.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
