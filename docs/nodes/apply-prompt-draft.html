MiniMax H3 Review / Apply Prompt Draft

Applies an accepted prompt draft to a timeline snapshot.

References and prompts1 output

Use it when: Use it after reviewing a Prompt Forge result.

In plain language

This turns an accepted prompt draft into timeline data that the Master can use. Applying a draft changes shot instructions, not already generated video frames.

Your first use: Connect the original timeline and reviewed draft. Enable acceptance when you are ready, then send the timeline JSON output to the Master’s timeline_data input. Do not connect it to prompt_text: that input expects plain prompt lines, not a timeline document.

Connections

Prompt Forge draft → draft; matching timeline JSON → timeline
STRING → Master timeline_data

How it works

  • apply false returns the original timeline string unchanged.
  • apply true verifies the draft’s source context and applies replace or append, returning updated timeline JSON.

How to use it

  1. Supply the same timeline snapshot used for drafting and connect the draft.
  2. Review the draft and choose replace or append.
  3. Set apply true, then use the returned STRING as the Master timeline_data input.

Limits and troubleshooting

  • Replacing changes the authored shot list; appending adds draft shots. This does not render them.
  • A returned timeline JSON is not a line-per-shot prompt_text string. Use the timeline_data input.
