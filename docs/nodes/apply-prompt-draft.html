Review / Apply Prompt Draft (Graph)

Apply a reviewed prompt proposal to timeline data.

Use it when: Separate writing a draft from replacing or appending authored clips.

1. What it does

New proposed clips are added to the timeline; this node does not render them.

2. Connect it

Existing timeline → timeline
Prompt Forge.draft → draft
timeline output → Master.timeline

3. First use

  1. Review the draft and confirm its source timeline still matches.
  2. Choose replace or append according to your intended edit.
  3. Leave apply off to pass through unchanged; enable it to apply.

7. Limits & troubleshooting

  • Applying a draft changes authoring data. It is not clip approval or model generation.
  • Stale/incompatible draft context is checked and can be rejected.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
