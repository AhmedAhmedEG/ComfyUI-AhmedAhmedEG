Reference Pack (Pool)

Prepare connected reference assets once, then let each clip choose its subset.

Use it when: Name, trim, crop, resize and describe pictures, videos and audio supplied by loader nodes.

1. What it does

Its visual stream is available to the clip; the paired soundtrack is not passed as that video’s audio.

2. Connect it

Load Image.IMAGE → Reference Pack.image_1
Load Video.VIDEO or frame batch → Reference Pack.video_1
Frame-batch soundtrack → Reference Pack.video_1_audio
Reference Pack.ref_pack → Master.ref_pack
Earlier Reference Pack.ref_pack → next.ref_pack_optional

3. First use

  1. Connect media loader outputs to matching inputs. Use the Edit Reference dropdown to work on one asset at a time.
  2. Give each reference a useful name. For video choose Video + Audio, Video Only, Audio Only or Single Frame.
  3. Open Resize and set video input preparation, usually Megapixels with the 0.5 MP default.
  4. Select references separately on each Master clip. Reset Settings affects the selected reference, not its source connection.

5. Practical examples

Use case 01

Use a video for motion without its sound

Set it up
Choose Video Only for that video reference and select it on a compatible clip.
Expect
Its visual stream is available to the clip; the paired soundtrack is not passed as that video’s audio.
Use case 02

Reduce expensive reference input

Set it up
Choose Megapixels and 0.5 on a large video.
Expect
Asset preparation changes its pixel dimensions before it reaches native model reference encoding. It does not change output canvas size.
Use case 03

Use one frame from footage

Set it up
Choose Single Frame, trim the useful range, then set Picked Frame time relative to that trimmed range.
Expect
The prepared reference is an image, so clip selection follows image-type limits.

7. Limits & troubleshooting

  • Native VIDEO carries timing and may carry audio. An IMAGE frame batch carries neither soundtrack nor intrinsic FPS; supply source FPS and paired audio separately.
  • Roles and Prompt Cast guide prompt writing. They do not replace clip reference selection or automatically force model endpoints.
  • No Add Pack Files or manual Refresh References button is needed: connect loader nodes; the editor watches connections and loader changes.
  • A bigger pool does not increase one clip’s allowed reference counts.
  • Each pack has four image, two video and two standalone audio sockets. Chain another pack for more connected media; clip limits still apply.
  • Native reference conditioning limits videos to 15 seconds each and 15 seconds total, and audio to 15 seconds each and 15 seconds total. Trim long sources before assignment.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
