Director FaceRefine

Track and refine a face crop, then blend it back into the video.

Use it when: Try local facial detail changes after the whole clip’s action and composition already work.

1. What it does

Only the tracked crop is refined and blended; no detected face means the clip is retained with a reported skip.

2. Connect it

Face Refine.face_refine → Master.face_refine

3. First use

  1. Install the chosen detector and connect the modifier to Master.
  2. Choose which face to track and a crop canvas. Start with a restrained strength.
  3. Describe the intended face appearance without requesting unrelated scene changes.
  4. Inspect the whole clip for identity drift, tracking errors and blending seams.

7. Limits & troubleshooting

  • Requires its detector dependencies and weights. Missing dependencies are errors rather than proof the feature ran.
  • A detector can select the wrong person, especially with multiple faces; inspect the result.
  • Extra sampling may alter identity or introduce temporal flicker. It is not a guaranteed face repair.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
