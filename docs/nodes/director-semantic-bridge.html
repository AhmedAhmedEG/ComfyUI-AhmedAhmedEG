Director Semantic Bridge

Configure a compatible learned conditioning adapter.

Use it when: Use only when you have the exact supported adapter weights and want to test their conditioning effect.

1. What it does

Conditioning is modified; it is not an added reference image or a LoRA.

2. Connect it

Semantic Bridge.semantic_bridge → Master.semantic_bridge

3. First use

  1. Install the compatible adapter weights and select them.
  2. Connect the modifier and begin with the supplied alpha.
  3. Compare the same prompt, seed and references with the modifier disconnected.
  4. Adjust alpha only after checking visual and motion effects.

7. Limits & troubleshooting

  • Exact compatible weights are required; arbitrary model files cannot be substituted.
  • This changes conditioning and therefore can change output. It does not guarantee better prompt adherence.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
