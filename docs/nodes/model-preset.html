Model Preset

Switch the REF2VA model between Base, Lightning LoRA and Fast H3 from one control.

Use it when: Keep all three prepared model branches in one workflow and choose which one generates, with the sampling values that model needs.

1. What it does

Samples with 8 steps, euler, simple, CFG 1 and shift 12/3, exactly as the Fast H3 workflow, using the int8 video VAE.

2. Connect it

Base branch (UNET → H3 SLA Attention) → base_model
Lightning branch (UNET → LoRA → H3 SLA Attention) → lightning_model
Fast H3 branch (UNET → Model Attention Backend → Block Sparse Attention) → fast_model
Video VAE → video_vae; Fast H3 int8 video VAE → fast_video_vae
model → Master.ref2va_model; video_vae → Master.video_vae; sampling → Director Settings.model_preset

3. First use

  1. Connect each prepared branch and both video VAEs.
  2. Connect model, video_vae and sampling as shown.
  3. Choose the preset. Only the selected branch loads.

4. Every option explained

preset

Setting

Which REF2VA model branch generates.

Use it when
Pick Fast H3 for speed, Lightning LoRA or Base for the existing look.
What changes
Selects the model, video VAE and sampling values passed on.
Keep in mind
Fast H3 ignores the step fields and always uses its required settings.
Choices, defaults & connection details

Type: COMBO · Initial value: Base · Required

Base
The base REF2VA model with the Base steps and the sampler, scheduler and CFG from Director Settings.
Lightning LoRA
The REF2VA model with the Lightning/turbo LoRA, using Lightning steps (normally 8).
Fast H3
The distilled Fast H3 model with its fixed settings: 8 steps, euler, simple, CFG 1, shift 12/3, and its int8 video VAE.

7. Limits & troubleshooting

  • Fast H3 sampling values are fixed because the distilled model is only valid with them.
  • Switching preset changes the model identity, so saved clips from another preset are not reused automatically.
  • The preset sets global sampling values; FL2VA clips use the same steps and scheduler.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
