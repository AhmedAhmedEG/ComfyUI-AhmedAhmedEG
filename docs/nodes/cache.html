Node reference · Enhancements

Cache

Reuse sufficiently similar internal model residuals during sampling.

Use it when: Test an optional speed/quality tradeoff after a stable baseline exists.

1. What it does

The model recomputes more often. Savings and output differences depend on the clip.

2. Connect it

Diffusion MODEL → Cache.model
Cache.MODEL → matching Master model input

3. First use

  1. Place Cache on the model branch you intend to test.
  2. Start conservatively; limit the active sampling interval and consecutive skips.
  3. Compare the same clip with caching disconnected.
  4. Read verbose statistics to see whether reuse actually occurred.

7. Limits & troubleshooting

  • Residual reuse approximates work and can affect detail or motion. It is not guaranteed pixel-identical to uncached sampling.
  • device controls cache storage, which trades VRAM against transfers. This is not the project’s latent disk cache.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
