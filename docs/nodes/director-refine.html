Director Refine

Rework a generated clip, optionally enlarging it first.

Use it when: Review a completed first pass before spending additional time on refinement.

1. What it does

Video is refined while first-pass audio is retained; improvement is not guaranteed.

2. Connect it

Refine.refine → Master.refine
Optional compatible model → Refine.refine_model
Optional image upscale model → Refine.upscale_model

3. First use

  1. Choose refine for the same resolution, upscale for enlargement plus diffusion, or latent_upscale for preparation without diffusion.
  2. Start with one pass and modest denoise. Steps are extra work after initial generation.
  3. Enable Confirm First Pass before the initial run if you want to inspect it before refining.
  4. Review the first pass, approve that stage on the timeline card, then run again to finish refinement without repeating an unchanged first pass.

5. Practical examples

Use case 01

Preserve sound while trying visual refinement

Set it up
Use backend=global, mode=refine, one pass, three steps and low denoise such as 0.2 as an experiment.
Expect
Video is refined while first-pass audio is retained; improvement is not guaranteed.
Use case 02

Enlarge with the same aspect

Set it up
Use mode=upscale, canvas_policy=follow and choose megapixels.
Expect
A target canvas is derived from the actual first-pass aspect and snapped to H3 dimensions before refinement.
Use case 03

Ten steps now, fifteen later

Set it up
Use Confirm First Pass to review an initial result, then a separate refinement pass.
Expect
This is not equivalent to twenty-five initial steps. Exact persistent sampler resume is not exposed.

7. Limits & troubleshooting

  • refine ignores target dimensions; upscale enlarges once before repeated passes; latent_upscale does not run extra diffusion.
  • global retains first-pass audio. sampler refines the joint audiovisual latent, so sound can change.
  • A previously completed clip without a matching staged first pass is not automatically a refinement-only source.
  • Strong denoise or repeated passes can change identity, motion and flicker. Compare First Pass and Final Output.
  • The memory planner is an estimate, not a guaranteed hard VRAM cap. Skip FL2V protects endpoints by default.

8. Check your setup

Confirm the model family, source media and setting scope before comparing output. A visible control is not proof that a missing provider or model actually ran.
